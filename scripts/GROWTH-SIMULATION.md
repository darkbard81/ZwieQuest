# 성장별 전투 승률 비교

```bash
node scripts/simulate-growth.js /tmp/zwiequest-growth 200
```

첫 인자는 결과 경로 접두사, 두 번째는 조건당 시행 수다. `.md` 승률표, `.csv` 집계, `.json` 상세 결과가 생성된다. DB와 실제 계정은 사용하지 않는다.

기본 조건:

- 캐릭터 레벨: 1, 5, 10, 20, 40
- 몬스터 레벨: 캐릭터와 동일, +1, +3, +5, +10
- 몬스터 등급: 일반부터 전설까지 각각 독립 비교 (출현 확률로 가중하지 않음)
- 캐릭터 능력치: `pointBudget(level)` 전부 균등 배분. 나머지는 STR, CON, DEX, PER, INT, RES 순서로 배분하며 성장 시 기존 능력치는 감소하지 않음
- 장비: 일반 롱소드·가죽갑옷 / 일반 화염 지팡이·로브, 두 조합 비교
- 장신구·특수 옵션·스킬 사용 없음. 매 전투 최대 HP와 새로운 상태로 시작
- 일반 몬스터 전체 변종을 균등 확률로 추첨. 몬스터의 포인트 배분·장비·파생 능력치와 전투는 실제 생성기와 `Game.tick()`을 사용

총 250조건 × 200전 = 50,000전이다. 각 조건의 승률은 전체 표본 대비 승리 비율이며 패배와 600초 시간 초과를 별도 집계한다. JSON과 CSV에는 95% Wilson 신뢰구간을 포함한다. 같은 seed는 몬스터 종류·능력치 배분과 전투 난수의 비교 기준을 맞추기 위해 재사용된다.

이 실험은 몬스터 레벨을 고정하므로 실제 지역의 출현 레벨 상한을 넘는 조건도 포함한다. 실제 사냥터의 통합 승률이나 스킬을 사용하는 캐릭터의 승률과는 조건이 다르다. 등급별 승률은 28변종의 혼합 결과이며 JSON의 `monsters`와 `variations`에서 종별 결과와 변종 표본 수를 확인할 수 있다.

`scenarioMonster()`는 실제 생성기의 변종 → 레벨 → 등급 추첨 순서를 이용해 등급 추첨만 고정한다. 생성기 순서가 변경되면 `tests/growth-simulation.test.js`와 어댑터를 함께 확인한다. 운영 생성 규칙은 변경하지 않는다.

기존 `simulate-equipment.js`, `simulate-tactics.js`는 무배분 캐릭터의 장비 비교용이다. 성장별 동레벨·고레벨 비교에는 `simulate-growth.js`를 사용한다.
