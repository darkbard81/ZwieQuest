# 512px 원본 영상 재추출 검증 — 2026-10-21

## 적용 결과

전사·마법사·바바리안·레인저·고양이·라미아 6종의 기존 원본 영상에서 6동작 × 24프레임, 총 864프레임을 다시 추출했다. 기존 256px 이미지를 확대하지 않았다. 원본 영상은 모두 544×544, 24fps, 145프레임이며 기존에 선택한 원본 프레임 인덱스를 그대로 사용했다.

- 영상 전체 프레임을 512×512 RGBA로 축소했다. 잘라내기·이동·프레임별 중심/발 정렬·캐릭터별 크기 보정을 하지 않았다.
- 기존 크로마키 제거 방식과 고양이·라미아의 승인된 외곽선 제거를 유지했다. 새로운 영상/그림 생성은 하지 않았다.
- 캐릭터별 6개의 동작 시트: 8열 × 3행, 각 4096×1536. 총 36개 PNG. 큰 합본 대신 동작별 시트를 사용한다.
- `sprite.json` schemaVersion 4에 시트 경로·512px 좌표·256px 표시 크기·원본 영상 경로/해시/FPS/프레임 번호/시간을 기록했다.
- 게임 캔버스와 여관 캐릭터의 논리 표시 셀은 256×256이다. 실제 그림의 크기는 원본 프레임에서 차지하는 면적에 따라 다르다. 모바일에서는 전체 캔버스의 반응형 축소가 추가로 적용된다.
- 공통 앵커 `(256,472)`, 모험 화면 위치와 방향 전환 정책을 유지했다. 여관 클릭 영역은 256px 표시 크기에 맞췄다. 캐릭터별 위치의 추가 조정은 이번 작업에 포함하지 않았다.
- 여관 선택 카드의 64px 미리보기는 새 Idle 시트를 사용하며, 고정 초상화는 Idle 0번 프레임의 `(112,48,288,288)` 영역에서 다시 만들었다.
- 모든 캐릭터의 Idle 시트와 현재 선택한 캐릭터의 나머지 5동작만 로드한다. 선택 변경 후 이전 캐릭터의 비대기 시트를 해제한다. 안정 상태에서 11개 시트를 유지하며 전환 중에는 비동기 로드가 잠시 겹칠 수 있다.

## 재생 흐름

이전: 256px 셀 144개가 든 캐릭터별 합본 한 장 → 합본 좌표로 재생.

이후: 원본에서 재추출한 512px 셀 → 동작별 시트의 좌표로 재생 → 캔버스에서 0.5배 표시. 첫 로드가 끝나지 않은 동작은 Idle 첫 프레임을 잠시 표시한다. 캐릭터 선택 시 모든 동작을 미리 로드한다.

동작 선택과 시간은 유지했다: Idle 2000ms 반복, Walk 1200ms 반복, Attack 650ms, Hit 360ms, Victory 2000ms, Down 1500ms 후 마지막 프레임 유지. 전투 판정·행동 주기·스킬 로직은 이번 변경에서 수정하지 않았다.

## 원본의 한계

바바리안 `Side_Down` 출력 12~23번(12프레임)은 오른쪽 머리카락 끝이, 라미아 `Front_Victory` 5~8번(4프레임)은 머리카락 윗부분이 영상 경계에 닿거나 잘려 있다. 원본 프레임과 출력 비교로 확인했으며 이번 변환에서 새로 발생한 잘림이 아니다. 원본 구도 유지 요청에 따라 크기·위치를 보정하지 않았다. 원본 영상에 포함된 캐릭터별 크기 차이와 동작 중 위치 이동도 그대로 남는다.
