# 랜덤 몬스터와 도감

일반 경로 도착 시 기본 조우 확률은 전투 20%, 보물 5%, 통과 75%다. 관리자 설정 → 확률관리에서 탐험 확률과 장비 획득 확률을 조절하고 확정하면 모든 계정의 다음 추첨부터 적용된다. 설정은 서버 재시작 후에도 유지된다. 보물상자는 금화만 지급한다. 보스도 몬스터 템플릿과 아래 공통 능력치 공식을 사용하며 보스 보상·귀환 규칙은 유지한다.

## 생성

`data-templates/monster/*.json`은 기본 HP 50, 레벨별 HP 증가량 10, CON 비율 보너스 5%, A/B 능력치, variation을 정의한다. 각 variation은 고유 ID, 이름, 512px 이미지 `img_path`, 128px 도감 이미지 `icon_path`, 스킬, 무기와 외피를 가진다. 이미지는 lossless WebP다.

하피도 슬라임과 같은 7개 피해 유형을 가진다. `harpy.json`은 기본 수치와 유형별 약점을 슬라임과 공유하며, 이름·설명·공격·깃털 명칭을 하피에 맞춘다. 모든 하피 무기 공격은 회피(DEF)를 대상으로 한다. 선택적인 `attackName`은 전투 로그의 공격명에 사용하며, 없는 기존 몬스터는 종전 공격명을 유지한다. 하피 원본 PNG는 `art-workbench/monsters/harpy`에 보존하고, 투명도를 유지한 512×512 본 이미지와 128×128 도감 아이콘을 `public/assets/monster/harpy`에 둔다.

골렘은 `golem.json`의 7개 피해 유형으로 추가한다. 기본 수치와 유형별 약점은 기존 몬스터와 같고, 골렘의 모든 무기 공격은 회피(DEF)를 대상으로 한다. 원본 PNG는 `art-workbench/monsters/golem`에 보존하며, 512×512 무손실 WebP와 128×128 도감 아이콘은 `public/assets/monster/golem`에 둔다.

유령은 `ghost.json`의 7개 피해 유형으로 추가한다. 기본 수치와 유형별 약점은 기존 몬스터와 같고, 유령의 모든 무기 공격은 회피(DEF)를 대상으로 한다. 원본 PNG는 `art-workbench/monsters/ghost`에 보존하며, 512×512 무손실 WebP와 128×128 도감 아이콘은 `public/assets/monster/ghost`에 둔다.

`data-templates/regions.json`의 지역별 규칙으로 무기의 damageTypes에 금지 타입이 하나라도 포함된 variation을 제외한다. 남은 variation과 지역 레벨 범위에서 각각 균등 추첨한다. 후보가 비면 시작 시 검증 오류를 낸다.

| 지역 | 레벨 | 생성 제외 피해 타입 |
| --- | --- | --- |
| 새싹마을 | 1–5 | 없음 |
| 홍련 분화구 | 5–20 | cold / 동결 |
| 백야 설원 | 5–20 | fire / 소각 |
| 산성 호수 | 5–20 | lightning / 충격 |
| 낙뢰 고원 | 5–20 | corrosion / 부식 |

등급 확률은 장비와 동일한 일반 60%, 양질 25%, 우수 10%, 고급 4%, 전설 1%다. 하나의 등급을 무기와 외피에 공통 적용한다. 장비의 등급별 명중·관통·피해 배율·방어도 보너스를 사용하며 특별 접두/접미 옵션은 붙이지 않는다. 일반은 `슬라임(베기)`, 나머지는 `양질 슬라임(베기)`처럼 표시하며 레벨은 별도로 표시한다.

레벨 L의 배분 포인트는 `10 + floor(L / 2)`다. 각 포인트를 STR/CON/DEX/PER/INT/RES 중 하나에 균등 배분한 뒤 종의 A 능력치에 더한다. 명중·방어 파생 능력치는 캐릭터와 계산식을 공유하며 명중·4방어에 레벨 보너스 `3 × floor(L / 2)`를 더한다. 캐릭터·일반 몬스터·보스의 HP는 `floor((50 + 10 × (L−1)) × (1 + 0.05 × CON)) + 장비 HP`로 동일하게 계산한다. 모든 일반 몬스터 템플릿은 `hp:50`, `hpGrowth:10`, `hpConPercent:5`를 사용한다. 일반 몬스터의 레벨은 플레이어 레벨이나 장비에 연동되지 않는다. 보스는 전투 시작 시 캐릭터와 같은 레벨이며 전설 등급으로 고정한다. CON을 포함한 능력치 포인트는 일반 몬스터와 같은 규칙으로 배분한다. 보스 HP에는 경로 깊이·위험도·별도 배율을 더하지 않는다.

지역별 보스는 `regions.json`의 `bossDamageType`에 맞는 변종 중 무작위로 선택한다. 홍련 분화구는 fire(소각), 백야 설원은 cold(동결), 산성 호수는 corrosion(부식), 낙뢰 고원은 lightning(충격)이다. 현재 각 속성마다 슬라임·하피·골렘·유령 4종이 후보이며 무기와 외피 모두 전설 등급이다. 일반 몬스터의 지역 레벨 상한 20은 보스에 적용하지 않는다. 마을에는 보스가 없다. 보스 조우·처치도 해당 변종의 도감에 집계한다.

생성 결과 전체를 계정 상태의 enemy에 저장한다. 재접속과 서버 재시작 시 레벨·등급·장비·배분·남은 HP·행동 준비도를 재추첨하지 않는다. 기존 전투 중인 구형 적도 완료까지 유지한다.

## 보상

캐릭터 레벨을 C, 몬스터 레벨을 M이라고 한다. 판정에는 경험치를 지급하기 전 캐릭터 레벨을 사용한다.

| 레벨 차이 M−C | 경험치 (현재 xpPerLevel=40) | 장비 |
| --- | --- | --- |
| −1 이하 | 1 (고정) | 기본 25% 추첨 |
| 0 | 4C | 기본 25% 추첨 |
| +1 | 5C | 기본 25% 추첨 |
| +2 | 6C | 기본 25% 추첨 |
| +3 | 7C | 기본 25% 추첨 |
| +4 이상 | 8C | 기본 25% 추첨 |

필요 경험치는 `40C`로, 경험치 0에서 시작하면 동급 몬스터 10마리를 잡아 한 레벨 오른다. 높은 레벨 보너스는 최대 2배다. 등급은 경험치에 영향을 주지 않는다. 레벨업 직전의 동급 몬스터도 장비 추첨 대상이다.

골드는 `floor((4 + 2M) × 등급 배율)`이다. 배율은 일반 1, 양질 1.25, 우수 1.5, 고급 1.75, 전설 2다. 낮은 레벨 몬스터도 경험치 1과 골드를 지급하며, 다른 몬스터와 동일하게 장비를 전역 획득 확률(기본 25%)로 추첨한다. 장비 추첨에 당첨되면 기존 무기/갑옷/장신구 및 장비 등급 규칙을 따른다.

일반 몬스터 상한은 20이므로 레벨 21 이상 캐릭터는 일반 전투마다 경험치 1을 얻고, 장비는 계속 전역 획득 확률(기본 25%)로 획득한다. 캐릭터 레벨 상한은 새로 두지 않는다. 보스 보상은 별도 기존 규칙이다. 보물상자는 경로 위험도에 따른 기존 금화만 지급하며 경험치와 장비는 지급하지 않는다.

## 도감

표시 순서는 최신 템플릿의 **유형 codexOrder → 유형 내 variation codexOrder → variation ID**다. 파일명·유형 키·변형 ID·추첨 후보 배열 순서는 바꾸지 않는다. 기존 저장의 조우 순서는 보존하고 서버 스냅샷에서 도감 표시 순서만 정렬한다. 번호는 화면에 출력하지 않는다. 템플릿 변경은 서버 재시작 후 기존 기록에도 적용된다. 삭제된 템플릿의 과거 기록은 마지막에 ID순으로 유지한다.

| 유형 | codexOrder |
| --- | --- |
| 슬라임 (slime) | 10 |
| 하피 (harpy) | 20 |
| 골렘 (golem) | 30 |
| 고스트/유령 (ghost) | 40 |

각 유형 안의 변형 번호는 베기 10, 관통 20, 부수기 30, 소각 40, 동결 50, 충격 60, 부식 70이다. `codexOrder`는 필수 양의 안전한 정수다. 유형 번호는 전체 유형에서, 변형 번호는 같은 유형 안에서만 유일해야 한다. 다른 유형끼리 변형 번호를 공유하는 것은 정상이다. 향후 삽입용 15 같은 정수도 허용한다.

`npm test`의 `tests/bestiary-order.test.js`가 초기 번호, 중복 유형·변형 번호의 실제 거부, 누락·잘못된 값, 10의 배수가 아닌 번호 허용, 저장 복원과 최신 템플릿 정렬, 추첨 후보 순서 보존을 확인한다. 동일 검증은 서버 시작 시에도 실행되어 잘못된 템플릿을 조기에 거부한다.

모험 정보의 도감은 **계정에서 실제 조우한 variation ID**당 한 칸을 표시한다. 아직 만나지 않은 유형의 자리나 정보는 노출하지 않는다. 전투가 시작되면 등록되므로 처치하지 않아도 남는다.

같은 variation의 다른 등급·레벨은 새 칸을 만들지 않는다. 조우 횟수, 처치 횟수, 발견 레벨 범위, 등급별 조우 횟수, 지역 목록, 최근 조우 개체의 능력치·무기·외피·약점·스킬을 상세 화면에 기록한다. 배경에는 해당 variation의 512px 원본, 목록에는 128px 아이콘 파일을 43×43px로 표시한다. 도감 슬롯은 가방 아이템과 동일한 45×49px이며 아이콘만 표시하고 이름은 툴팁과 상세 화면에서 확인한다. 기록은 계정 캐릭터들이 공유하며 계정 초기화 시 함께 지워진다.

접근은 클릭·터치·키보드 Enter/Space, 닫기는 닫기 버튼·Escape를 지원한다. 로그아웃 시 도감 화면의 계정 기록도 비운다.

일반 몬스터·보스 모두 `max(1, 100 + DEX × 5) × (1 − 방어구 패널티) × (1 − 무기 패널티)` 행동속도를 공유한다. 현재 몬스터 자연 공격의 무기 패널티는 0%다. 슬라임 자연 외피는 `armorCategory:natural`, 패널티 0%이며 DEX 보정은 없다. 저장 적은 기존 DEX와 외피 패널티로 속도 필드만 보완하며 정보가 없으면 패널티 0%다. 적·드롭 재추첨 없이 `generationVersion:1`과 도감·보상 경로를 유지한다.
