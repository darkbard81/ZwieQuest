# 랜덤 몬스터와 도감

일반 경로 도착 시 조우 확률은 전투 12.5%, 보물 12.5%, 통과 75%다. 보스와 보물은 기존 규칙을 유지한다.

## 생성

`data-templates/monster/*.json`은 종별 기본 HP, 레벨별 HP 증가량, A/B 능력치, variation을 정의한다. 각 variation은 고유 ID, 이름, 512px 이미지 `img_path`, 128px 도감 이미지 `icon_path`, 스킬, 무기와 외피를 가진다. 이미지는 lossless WebP다.

`data-templates/encounters.json`의 지역별 규칙으로 무기의 damageTypes에 금지 타입이 하나라도 포함된 variation을 제외한다. 남은 variation과 지역 레벨 범위에서 각각 균등 추첨한다. 후보가 비면 시작 시 검증 오류를 낸다.

| 지역 | 레벨 | 생성 제외 피해 타입 |
| --- | --- | --- |
| 새싹마을 | 1–5 | 없음 |
| 홍련 분화구 | 5–20 | cold / 동결 |
| 백야 설원 | 5–20 | fire / 소각 |
| 산성 호수 | 5–20 | lightning / 충격 |
| 낙뢰 고원 | 5–20 | corrosion / 부식 |

등급 확률은 장비와 동일한 일반 60%, 양질 25%, 우수 10%, 고급 4%, 전설 1%다. 하나의 등급을 무기와 외피에 공통 적용한다. 장비의 등급별 명중·관통·피해 배율·방어도 보너스를 사용하며 특별 접두/접미 옵션은 붙이지 않는다. 일반은 `슬라임(베기)`, 나머지는 `양질 슬라임(베기)`처럼 표시하며 레벨은 별도로 표시한다.

레벨 L의 배분 포인트는 `10 + floor(L / 2)`다. 각 포인트를 STR/CON/DEX/PER/INT/RES 중 하나에 균등 배분한 뒤 종의 A 능력치에 더한다. 파생 능력치는 캐릭터 계산식을 공유한다. 슬라임 HP는 `10 + 2 × (L−1) + 5 × CON`, 숙련 LB는 `floor((L−1)/3)`다. 몬스터의 레벨은 플레이어 레벨이나 장비에 연동되지 않는다.

생성 결과 전체를 계정 상태의 enemy에 저장한다. 재접속과 서버 재시작 시 레벨·등급·장비·배분·남은 HP·턴을 재추첨하지 않는다. 기존 전투 중인 구형 적도 완료까지 유지한다.

## 보상

캐릭터 레벨을 C, 몬스터 레벨을 M이라고 한다. 판정에는 경험치를 지급하기 전 캐릭터 레벨을 사용한다.

| 레벨 차이 M−C | 경험치 (현재 xpPerLevel=40) | 장비 |
| --- | --- | --- |
| −1 이하 | 0 | 없음 |
| 0 | 4C | 25% 추첨 |
| +1 | 5C | 25% 추첨 |
| +2 | 6C | 25% 추첨 |
| +3 | 7C | 25% 추첨 |
| +4 이상 | 8C | 25% 추첨 |

필요 경험치는 `40C`로, 경험치 0에서 시작하면 동급 몬스터 10마리를 잡아 한 레벨 오른다. 높은 레벨 보너스는 최대 2배다. 등급은 경험치에 영향을 주지 않는다. 레벨업 직전의 동급 몬스터도 장비 추첨 대상이다.

골드는 `floor((4 + 2M) × 등급 배율)`이다. 배율은 일반 1, 양질 1.25, 우수 1.5, 고급 1.75, 전설 2다. 낮은 레벨 몬스터는 골드만 지급한다. 장비 추첨에 당첨되면 기존 무기/갑옷/장신구 및 장비 등급 규칙을 따른다.

일반 몬스터 상한은 20이므로 레벨 21 이상 캐릭터는 현재 일반 전투에서 경험치와 장비를 얻지 못한다. 캐릭터 레벨 상한은 새로 두지 않는다. 보스·보물 보상은 별도 기존 규칙이다.

## 도감

모험 정보의 도감은 **계정에서 실제 조우한 variation ID**당 한 칸을 표시한다. 아직 만나지 않은 유형의 자리나 정보는 노출하지 않는다. 전투가 시작되면 등록되므로 처치하지 않아도 남는다.

같은 variation의 다른 등급·레벨은 새 칸을 만들지 않는다. 조우 횟수, 처치 횟수, 발견 레벨 범위, 등급별 조우 횟수, 지역 목록, 최근 조우 개체의 능력치·무기·외피·약점·스킬을 상세 화면에 기록한다. 배경에는 해당 variation의 512px 원본, 목록에는 128px 아이콘을 사용한다. 기록은 계정 캐릭터들이 공유하며 계정 초기화 시 함께 지워진다.

접근은 클릭·터치·키보드 Enter/Space, 닫기는 닫기 버튼·Escape를 지원한다. 로그아웃 시 도감 화면의 계정 기록도 비운다.
