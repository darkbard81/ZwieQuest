# 액세서리 규칙

액세서리는 기존 `charm` 슬롯 1개를 사용한다. 직접 ACC·AR·HP 같은 파생값이나 별도 특수 효과를 부여하지 않고, 기본 능력치 6종만 강화한다. 신규 이미지 6개는 내장 image_gen으로 생성했으며 `public/assets/equipment/*-charm-v1.png`에 원본 투명 PNG를 저장한다. 생성 프롬프트와 해시는 `accessory-image-prompts.json`에 기록한다.

| 종류 | 주 능력치 |
|---|---|
| 완력의 부적 | STR |
| 활력의 부적 | CON |
| 민첩의 부적 | DEX |
| 통찰의 부적 | PER |
| 지혜의 부적 | INT |
| 의지의 부적 | RES |

| 등급 | 확률 | 주 능력치 | 추가 능력치 |
|---|---:|---:|---:|
| 일반 | 60% | +1 | 없음 |
| 양질 | 25% | +1 | +1 |
| 우수 | 10% | +2 | 없음 |
| 고급 | 4% | +2 | +1 |
| 전설 | 1% | +2 | +2 |

카테고리 6종은 균등 선택한다. 추가 능력치는 주 능력치를 제외한 나머지 5종에서 균등 선택한다. 같은 능력치 중복은 없으며, 1% 특수 옵션 판정도 없다. 저장된 보너스는 재접속·전직 시 다시 뽑지 않는다. 판매가는 무기·방어구와 같은 등급별 가격을 사용한다.

## 획득과 시작 장비

- 일반 전투·보스 승리당 25% 확률로 아이템 1개. 무기·방어구·부적 선택 확률은 각각 1/3.
- 보물 상자는 부적 6종 중 1개를 확정 지급하며 같은 5등급 확률을 사용한다. 경로 위험도에 따라 부적 희귀도를 별도로 높이지 않는다.
- 신규 캐릭터의 시작 무기·갑옷은 기존처럼 일반 롱소드/가죽 갑옷 또는 일반 화염 지팡이/로브다. 부적은 시작 시 지급하지 않으며 전투 승리나 보물 상자에서 획득한다. 모든 시작 장비는 신규 카탈로그를 사용한다.

## 능력치 적용

클래스 기본값에 장착 아이템의 STR·CON·DEX·PER·INT·RES를 각각 한 번 합산한 뒤 기존 파생 공식을 적용한다. 갑옷 DEX 패널티도 이 단계에서 함께 합산한다. 기존 공식은 바꾸지 않는다. 따라서 STR은 피해와 FOR, CON은 최대 HP와 FOR, DEX는 REF·선공, PER은 ACC·REF, INT는 WIL·전술 효과, RES는 DEF·WIL에 반영된다.

장비 변경은 이후 판정에 적용하지만 전투 중 선공 순서는 재계산하지 않는다. 방어태세 등 이미 발동한 전술 버프는 기존 라운드 수명을 유지한다. CON 장착으로 최대 HP가 늘어도 현재 HP를 무료 회복하지 않으며, 해제해서 최대 HP가 감소하면 현재 HP를 그 이하로 제한한다.

## 구형 장비 전환

사용자가 기존 부적 삭제·신규 6종 전환 및 기본 장비 재구성을 명시적으로 요청했다. 운영 반영 전에 SQLite 전체 백업과 복사본 검증을 수행한다.

- 구형 새벽의 부적: 신규 부적 6종 중 하나로 교체한다. 기존 ACC/WIL 효과는 제거한다.
- 구형 여행자의 검/지팡이: 신규 롱소드/화염 지팡이로 교체한다.
- 구형 수호자의 외투: 현재 전사이면 가죽 갑옷, 마법사이면 로브로 교체한다.
- 구형 3단계 등급의 순서를 보존해 tier 0/1/2 이상을 일반/양질/우수에 대응시킨다. 기존 ‘고급’이라는 이름은 구 체계의 중간 등급이므로 신규 ‘양질’로 전환한다.
- 교체 무기·방어구에 특수 옵션을 추가로 뽑지 않는다. 이미 신규 카테고리인 장비의 수치·옵션은 보존한다.
- 아이템 ID·개수·장착 슬롯 연결을 유지해 중복 지급이나 장착 해제가 생기지 않게 한다. 구형 아이템의 이름·효과·이미지는 신규 카탈로그 값으로 완전히 대체한다.
- 전환 후 저장된 신규 templateId로 중복 전환을 막는다. 진행 중 전투의 AP·행동자·라운드·이미 사용한 전술 효과를 다시 실행하지 않는다. 현재 HP는 새 최대 HP까지만 제한한다.

생성·등급·파생 능력치·전술·장착·재시작 보존은 `tests/accessories.test.js`와 `tests/equipment-persistence.test.js`에서 검증한다.
