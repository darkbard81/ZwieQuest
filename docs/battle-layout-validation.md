# 전투 캐릭터·몬스터 표시 통일 — 2026-10-21

## 변경

- 몬스터의 기본 표시 크기를 196×196에서 캐릭터와 같은 256×256으로 변경했다. 이미지 로딩 중 임시 몬스터도 같은 규격이다.
- 몬스터 기준점을 이미지 하단 `(0.5,1)`에서 캐릭터와 동일한 `(0.5,472/512)`로 맞췄다. 원본 512px 기준 `(256,472)`이다.
- 공통 전투 바닥 Y는 317이다. 좌우 중심은 캐릭터 X=148, 몬스터 X=364로 정했다. 쓰러질 때도 캐릭터 X=148을 유지한다.
- 기존 호흡·공격·피격·사망 연출은 유지하므로 연출 중 몬스터 크기와 X는 기본값에서 일시적으로 변한다. 적중 글자는 변경된 몬스터 위치를 따른다.
- 보물상자는 기존 84px, 하단 기준점, X=398을 유지한다. 몬스터와 같은 스프라이트 객체를 사용하므로 전환 시 기준점을 명시적으로 복원한다.
- 첫 실제 스크린샷에서 확대된 몬스터의 머리를 체력 표시가 덮었다. 양쪽 체력 표시를 각 중심 위로 정렬하고 Y=44로 올려 해결했다. 여행/여관의 체력 표시 위치는 변경하지 않았다.

## 검증

운영 계정과 분리된 임시 데이터베이스 및 서버에서 실제 Chromium/PixiJS로 확인했다.

- 변경 전후 1280×900 데스크톱, 360×740 모바일 세로, 844×390 가로 화면 캡처.
- 데스크톱의 전사/골렘과 모바일 세로의 라미아/하피 화면을 직접 검토했다. 머리를 가리던 체력 표시가 해소되었고, 두 대상이 화면 내 좌우에 배치된다.
- 6종 캐릭터와 골렘·유령·슬라임·하피 조합의 동작 확인. 공격 중 몬스터 오른쪽 경계가 캔버스를 벗어나지 않음, 공통 바닥 Y 유지, 캐릭터 쓰러짐 시 위치 유지, 보물상자 크기/기준점 복원 검증.
- 동작 감소 설정에서 몬스터 256×256과 캐릭터/몬스터 앵커·바닥 좌표 일치 확인. 일반 설정에서는 기존 호흡·공격 연출 진행 확인.
- 전투 체력 표시가 몬스터 중심 X에 정렬되고, 표시 하단이 논리 Y=72보다 위에 위치함을 확인했다.
- 페이지 오류·자산 HTTP 오류 0건, 검사한 화면의 가로 넘침 없음.
- `npm test`: 241개 통과, 실패 0개. `git diff --check` 통과.
- 운영 HTTPS가 새 `render.js`, `style.css`를 로컬 파일과 동일한 해시로 제공함을 확인. `/api/health` 정상. 정적 파일 변경이라 서버 재시작 없이 적용된다.

## 범위와 남는 차이

원본 이미지의 투명 여백·그림 점유율은 변경하지 않았다. 공통 256px 셀과 기준점이 같아도 캐릭터/몬스터의 실제 실루엣 크기와 발 위치는 원본에 따라 차이가 남는다.

844×390처럼 높이가 매우 낮은 가로 화면에서는 기존 고정 높이 UI 때문에 화면 하단 일부가 보이지 않는다. 이번 배치로 새로 생긴 문제는 아니며 전체 창/뷰포트의 높이 대응은 변경하지 않았다. 이 화면은 전체 플레이 영역이 보인다고 판정하지 않았다.

변경 파일: `public/render.js`, `public/style.css`, 이 문서. 기존 미커밋 변경 보존, 커밋·푸시 없음.
