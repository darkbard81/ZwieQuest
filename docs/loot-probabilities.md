# 획득 확률과 종류 비율

몬스터·보스 처치 및 보물상자는 공통 `dropPercent`(기본 25%)로 획득 여부를 먼저 추첨합니다. 성공한 경우 `weaponWeight`, `armorWeight`, `charmWeight`, `skillWeight`를 가중치로 무기·방어구·액세서리·스킬 중 1개를 고릅니다. 기본값은 각각 1입니다. 가중치 0은 해당 종류를 제외합니다. 각 값은 0~100 정수이며 합계가 양수여야 합니다. 관리자 화면에서는 탐험과 같은 한 막대의 3개 경계 손잡이로 네 종류의 비중을 1% 단위로 조절합니다. 합계는 항상 100%이고 경계는 서로 넘어가지 않으며 0% 구간도 허용합니다. 기존 가중치는 합계 100%가 되도록 최대 나머지 방식으로 반올림해 표시하며, 종류 경계를 수정하지 않는 한 원래 저장 비율은 보존합니다. 종류 경계를 수정하면 구간 너비(정수 %)를 가중치로 저장합니다.

기본 설정의 각 종류 실제 획득 확률은 사건당 6.25%(25% × 25%)입니다. 금화 및 경험치는 기존 규칙대로 지급합니다. 장비 등급·특수 옵션 확률도 유지합니다. 스킬 분기는 계정의 미습득 대상만 균등 추첨하고 자동 장착하지 않습니다. 모두 습득하면 해당 분기에서 추가 지급 없이 끝나며 장비로 재추첨하지 않습니다.

기존 SQLite 확률 설정에 새 가중치가 없으면 1씩 보충하여 읽습니다. 기존 전투·보물·통과·획득 확률과 설정 revision은 보존합니다. 이후 관리자 확정 시 새 필드까지 저장합니다. 서버는 잘못된 값·일반 사용자 변경·구 버전 동시 변경을 거부하며 같은 요청 ID 재전송은 중복 적용하지 않습니다. 기존 4개 필드만 보내는 오래된 관리자 화면은 새로고침해야 합니다.

단일 구간 슬라이더 검증: 확률·HTTP 및 100% 변환 테스트 5개 통과. 격리 Chromium에서 데스크톱 1280×800·모바일 360×740의 세 손잡이 드래그·키보드 조작, 경계 교차 방지, 겹친 손잡이 개별 조작, 0% 구간, 20:35:25:20 저장·복원, 다른 설정 변경 시 기존 1:1:1:1 유지까지 확인했습니다. 스크린샷과 결과는 `art-workbench/partition-qa/`에 보관합니다. 운영 설정은 바꾸지 않았으며 정적 파일 2개의 운영 HTTPS 제공본 일치를 확인했습니다.
