# 무기·방어구 규칙 v1 — 이슈 #1 구현 기록

> 후속 이슈 #2에서 자유 장착·무기별 명중 대상·라운드 전술·기존 갑옷 DEX 이관을 적용했다. 현재 전투 규칙은 [전투 규칙 v2](combat-rules.md)가 우선한다. 아래 클래스 제한·강타 및 시뮬레이션 결과는 #1 적용 시점의 기록이다.

원본: https://github.com/darkbard81/ZwieQuest/issues/1

## 적용 범위

`data-templates/equipment.json`은 서버만 읽는 원본 목록이다. 전사 무기 11종, 마법사 지팡이 4종, 두 직업 공용 방어구 9종과 5등급 규칙을 정의한다. 몬스터 원형 목록과 부적 개편은 범위 밖이다. 새 규칙은 새로 생성되는 무기·방어구에만 적용한다.

생성 순서는 카테고리 → 등급 → 등급 보정 → 독립 특수 옵션이다. 등급은 성능 점수로 역산하지 않는다. 완성된 아이템은 UUID, templateId, rulesVersion, gradeId, 이름, 피해 범위와 등급 배율, 최종 ACC/PEN/AR, 타입, 특수 옵션, 판매 가격을 `account_state.body.inventory`에 저장한다. 다시 로그인하거나 서버를 재시작할 때 추첨하지 않는다. 이후 템플릿을 바꿔도 기존 아이템은 바뀌지 않는다. DB 스키마 변경은 없다.

## 사용자 승인으로 확정한 값

- 승리한 몬스터·보스 전투마다 25% 확률로 장비 **1개**. 성공한 경우 무기·방어구·부적을 각각 1/3 확률로 선택한다. 무기·방어구는 해당 카테고리 안에서 균등 선택하고, 두 직업 모두 모든 무기를 얻는다. 부적은 [액세서리 규칙](accessory-rules.md)의 기본 능력치 보너스와 동일한 5등급 확률을 사용한다. 패배·이동·보물 상자에서는 무기·방어구를 지급하지 않는다. 보물 상자는 기존 부적 보상을 유지한다. 신규 캐릭터의 일반 시작 무기·갑옷 지급은 유지한다.
- 일반 60%, 양질 25%, 우수 10%, 고급 4%, 전설 1%. 지역·레벨 제한 없음.
- 무기 특수 옵션 1%, 방어구 특수 옵션 1%. 등급과 독립이다. 추가 옵션 확률은 **생성된 장비 기준**이다.
- 방어구는 두 직업 공용. 신규 방어구에는 AR만 부여하며 별도 HP·DEF 보너스는 없다. 구 방어구의 HP는 유지한다.
- Raw는 빗나감이면 0, 그 외 명중 단계에서는 저장된 고정 피해. STR·등급 피해율·강타·치명타·관통 배율을 적용하지 않는다. 명중 판정에 무기 ACC는 적용한다. Raw 무기는 현재 기본 목록에 없고, 전투 엔진과 검증만 지원한다.
- 시뮬레이션 결과 확인 후, 이번에는 이슈의 무기 수치와 기존 몬스터 공식을 유지하고 밸런스 조정을 후속으로 남기기로 승인했다.

## 계산과 표시

비 Raw 공격: 기본 범위에서 균등 정수 추첨 → 등급 피해율 → 강타 배율 → STR 배율 → 명중 단계 배율 → PEN−유효 AR 배율 → 마지막에 한 번 내림. 중간 내림은 없다. 강타는 기존 클래스 설정의 강타/기본 피해 비율(현재 두 직업 모두 1.5배)을 유지한다. 가방의 무기 피해 범위는 등급 보정까지 반영한 값이며, 강타·STR·상대 방어도는 실제 공격 때 반영한다.

피해 타입이 여럿이면 가장 낮은 유효 AR을 선택한다. 동률은 저장된 타입 순서로 결정한다. 추가 타입은 추가 타격이 아니라 상성 선택지다. 무기 특수 옵션은 기존에 없는 비 Raw 타입 1개(최대 3타입)와 접두사, 방어구 특수 옵션은 기존에 보정이 없는 비 Raw 타입 1개에 +1~+4 균등 보정과 접미사다.

할버드는 베기·때리기 2타입이다. 방어구 약점은 등급에 따라 바뀌지 않으며 공통 AR만 오른다. 모든 기존 몬스터 공격은 기존 몸통 박치기와 일치하도록 때리기로 취급한다. 별도의 몬스터 타입 목록은 후속 설계 대상이다.

구 무기에는 기존 클래스 기본/강타 피해와 저장된 power/PEN을 그대로 적용한다. 무기를 해제한 맨손은 기본 피해 1(강타 시 기존 배율)이며 때리기다. 새 마법 지팡이를 해제하는 것이 더 강해지는 문제를 피하기 위한 기본값이다. 전직으로 지급되는 시작 무기는 일반 고정이며 특수 옵션이 없다.

판매 가격은 일반 12G부터 등급당 14G 증가(12/26/40/54/68G), 특수 옵션 가격 가산 없음. 기존 장비는 저장된 가격을 유지한다. 실시간 장착은 다음 타격부터 반영되고 장착 중 판매는 금지한다.

기존 `charmRareChance`/`charmRiskRareChance`는 더 이상 사용하지 않는다. 무기·방어구·부적의 등급 확률은 JSON 카탈로그 한 곳에서 관리한다.

## 이미지

내장 imagegen으로 카테고리별 1회씩 생성한 PNG 24개와 부적 PNG 6개의 원본은 `art-workbench/equipment/originals/`에 보관한다. 게임은 `public/assets/equipment/*-v1.webp`의 128×128 무손실 WebP 사본을 가방과 장착 슬롯에서 사용하며 투명 배경을 유지한다. 축소본 규격·해시는 `docs/equipment-runtime-images.json`에 기록한다. 생성 프롬프트와 파일 메타데이터는 `docs/equipment-image-prompts.json`에 기록한다.

## 검증 및 후속 밸런스

- `npm test`: 기존 테스트 및 장비 확률·타입·Raw·즉시 장착·구 장비 저장/판매·HTTP 재시작 검증.
- `node scripts/simulate-equipment.js <출력.json>`: 두 직업 × 4레벨(1/10/20/40) × 5등급 × 200개 고정 시드 = 8,000전. 단계 10 위험 경로 보스, 일반 시작 갑옷 고정, 부적·특수 옵션 없음. 장비에 따른 몬스터 자동 보정은 없다.
- 1레벨 일반 롱소드 전사 승률 98.5%, 일반 화염 지팡이 마법사 1%. 전설 무기는 각각 100%, 99.5%. 일반 갑옷을 고정한 특정 보스 시나리오이며 전체 탐험 승률은 아니다.
- 40레벨 전설 전사 치명타 비율 약 89%, 전설 마법사 약 83%. 현재 플레이어와 몬스터의 방어 성장에 공통 LB가 적용되고 몬스터 AR은 레벨에 비례하지 않아 고등급 ACC/PEN 우위가 지속된다. 향후 DEF/REF/WIL·AR·HP 성장과 직업 간 피해 격차를 함께 검토해야 한다. 사용자 선택에 따라 이번에는 수정하지 않았다.
- 브라우저 검증은 실제 게임 UI와 장비 규칙을 사용하되 API/SSE를 테스트 데이터로 대체해 운영 계정을 변경하지 않는다. 설치 후 정적 HTML/JS/PNG는 실제 Caddy HTTPS 경로에서 읽는다. 별도 HTTP 테스트는 임시 SQLite DB에서 실행한다.
