# 스킬 목록과 실행 규칙

`data-templates/skills.json`(schemaVersion 3)에 활성 스킬 28개(직접 사용 16개, 숙련 ON/OFF 12개)를 정의합니다. 상태 정의는 [상태 효과 36종](status-effects.md), 아이콘 기록은 [생성 기록](skill-image-prompts.json)을 참고하세요.

## 첫 적용 목록

기본 지속시간은 아래 표와 같고, **모두 발동 시 INT 1당 +5%**를 적용합니다(최소 25%). 받는 약화 상태는 대상의 적용 직전 유효 RES 1당 추가로 3% 감소합니다(결의 배율 최소 25%, 음수는 연장). 공격 스킬은 장착 무기의 피해 타입·기본 피해를 사용하고 무조건 회피(DEF)를 상대로 무기 명중을 판정합니다. 무기 명중/치명타이고 대상이 살아 있으면 새 d20으로 ACC vs 스킬의 상태 방어를 판정합니다. 두 번째 판정도 명중/치명타일 때 상태를 적용합니다. 스킬 명중 보너스는 두 판정에 모두 적용하며, 명중 등급 전환·반사된 형상 소모·치명타 방해는 첫 무기 판정에만 적용합니다. Miss/Graze·상태 실패도 발동한 스킬 1회를 소비합니다. 상태 판정은 추가 피해·행동·횟수를 소비하지 않습니다.

## 실행·획득

- **별도 회복시간/쿨다운 없음.** DEX는 캐릭터의 다음 행동 간격에만 영향을 줍니다. 최대 6개 장착, 한 행동에 스킬 1개, 전투당 횟수 제한은 유지합니다.
- 직접 사용 스킬 클릭은 다음 행동에 예약만 합니다. 준비도와 체력/사용 횟수는 그대로입니다. 다음 행동에서 일반 공격 대신 한 번 발동하고 예약을 비웁니다. 같은 요청 재전송·다른 탭·중복 클릭으로 추가 발동하지 않습니다.
- 예약과 실제 발동 시 소유·장착·정의 활성·생존·전투/캐릭터/개인 행동 순번·매혹/지배·남은 횟수를 검사합니다. 회복은 회복 가능량도 양쪽에서 확인합니다.
- 실행 때 조건을 잃으면 비용 없이 취소하고 일반 공격합니다. 실행 가능한 공격은 빗나가거나 상태가 저항/상쇄되어도 사용 횟수를 차감합니다. 지속시간과 보정은 실제 발동 시의 능력치로 결정합니다.
- 반사된 형상은 피격 Hit/Crit마다 10을 잃고 0이면 제거합니다. Miss/Graze·자기 공격은 감소시키지 않습니다. 다시 적용하면 보너스 30, 지속시간은 긴 값을 유지합니다.
- 몬스터·보스 처치와 보물상자는 같은 획득 확률(기본 25%)을 사용합니다. 성공하면 무기·방어구·액세서리·스킬을 기본 1:1:1:1로 추첨합니다. 관리자 확률관리에서 획득 확률과 네 종류 비율을 변경할 수 있습니다. 스킬이 뽑히면 계정의 미습득 대상 중 하나를 균등 추첨합니다. 전부 배웠으면 추가 지급 없이 종료하며 다른 종류로 재추첨하지 않습니다. 금화·경험치 규칙은 유지합니다.
- 회복은 기존대로 기본 습득·처음 슬롯 1 장착입니다. 회복 외 27개는 처치·보물상자의 스킬 획득으로 얻습니다. 습득 목록은 계정 공용이며 같은 스킬을 여러 캐릭터에 동시에 장착할 수 있습니다. 6개 장착 슬롯·자동/수동·숙련 ON/OFF 설정은 캐릭터별로 독립 저장합니다. 한 캐릭터 안에서는 같은 스킬을 중복 장착할 수 없습니다. 스킬 탭에는 일괄판매와 다른 플레이어 장비 숨김을 표시하지 않으며 스킬은 개별·일괄 판매 대상에서 제외합니다.
- 기존 `skillCooldowns`는 불러올 때 빈 객체로 정리하며 더 이상 게임 판정이나 UI에 사용하지 않습니다. 기존 스킬·장착·횟수·예약은 보존합니다. 비활성 `dagger-mastery` 정의는 호환성을 위해 남깁니다. 기존 소유분은 `light-weapon-mastery`로 이관하며 슬롯과 ON 상태를 보존합니다.
- 예약, 상태, 주기 회복, 횟수 복구 모두 같은 게임 시간 스케줄러에서 처리합니다. 온라인 1배·오프라인 2배, 서버 정지 중에는 정지합니다. 사망/전투 종료에 예약·상태를 제거하고 새 전투에서 횟수를 초기화합니다.

## 몬스터

새로 생성한 슬라임은 쇠약의 일격, 골렘은 체질 고양, 하피는 발목 묶기, 유령은 정신 교란을 가집니다. 세 번째 개인 행동부터 사용할 수 있는 스킬을 일반 공격 대신 사용하며 전투당 1회입니다. 보스도 해당 종류의 계획을 따릅니다. 기존 저장된 전투의 적에게는 소급 지급하지 않습니다. 몬스터 공격도 명중 방어·상태 성공 조건·INT 지속시간·매혹/지배·상쇄·저항 규칙이 같습니다.

## 데이터 관리

`id`는 저장 식별자로 유지합니다. `enabled`, `grantOnCreate`, `equipByDefault`, `treasureDrop`, `useContexts`, `activationMode`, `perBattleLimit`이 획득·장착·사용 정책입니다. `iconPath`는 `/assets/skills/<id>-v1.webp` 형태의 로컬 이미지입니다.

`effect.type`은 `attack`, `status`, `heal`, `mirror`, `cleanse`, `dispel`을 지원합니다. 공격은 상태 판정용 `statusDefense`, `damageMultiplier`, `accuracyBonus`, `penetrationBonus`, `statusId`, `durationMs`를 사용합니다. 상태 부여는 `statusId`, `durationMs`, 반사된 형상은 `durationMs`, 회복은 `maxHpRate`, `intelligenceRate`를 사용합니다. 시간 단위는 ms이며 수식 문자열을 실행하지 않습니다. 기존 `accuracyBonus` 유지형은 호환 처리합니다. `toggleConsumesCycle:false`인 단검숙련 ON/OFF 정책은 유지합니다.

상태 정의의 `modifiers`는 이전 단계 효과까지 포함한 완전한 목록입니다. 상위 단계가 아래 단계의 능력치를 중복 합산하지 않습니다. 정의 변경은 정상 서버 재시작 후 적용됩니다.

## 검증과 범위

`npm test`는 임시 DB HTTP 회귀를 포함합니다. `tests/status-skills.test.js`는 36종 정의, 활성 스킬 목록, 네 방어, 단계/상쇄/저항, 명중 전환, 제어, 타이머·저장·오프라인, 상자 중복 방지, 몬스터 계획을 검사합니다.

첫 목록은 단일 대상 전투용이며 광역/파티/지면 이동 효과는 추가하지 않습니다. Raw 피해는 기존 규칙대로 고정 피해여서 일반 피해 증폭을 적용하지 않습니다. 36종 처리 기반 중 첫 목록에서 직접 부여하지 않는 상태도 테스트하며 이후 스킬 정의로 확장할 수 있습니다. 수치의 장기 밸런스는 실제 플레이 검수가 필요합니다.

## 전투 상태 UI

모험의 창 아래에는 수동 스킬 아이콘·예약/소진·사용 횟수만 표시합니다. 동일한 이미지 노드를 유지해 서버 갱신 중 깜박임을 방지합니다. 상태 효과는 캔버스 왼쪽에 모험가, 오른쪽에 몬스터 아이콘을 세로로 배치합니다. 아이콘은 부여한 스킬의 이미지를 사용하고, 경과한 지속시간 비율만큼 시계 방향으로 어두워집니다. 마우스 오버·키보드 포커스·터치 시 `절뚝거림(12.3초)` 형식으로 상태명과 남은 시간만 표시합니다.

상태의 최초 지속시간과 출처 스킬 ID는 저장·복원합니다. 같은 단계의 더 긴 지속시간으로 갱신할 때만 음영의 기준 시간을 다시 설정합니다. 기존 저장 상태에 출처가 없으면 능력치에 대응하는 아이콘을 사용하며, 최초 불러온 잔여 시간을 음영의 기준으로 삼습니다.

| --- | --- | ---: | ---: | ---: |
| 단검·숏소드·레이피어 숙련 | `weapon:light` | +2 | +10% | -10% |
| 롱소드 숙련 | `weapon:sword` | +2 | -5% | +10% |
| 손도끼 숙련 | `weapon:axe` | -2 | +0% | +25% |
| 메이스 숙련 | `weapon:mace` | +3 | -10% | +0% |
| 창 숙련 | `weapon:spear` | +3 | +0% | -10% |
| 할버드 숙련 | `weapon:polearm` | +0 | -10% | +20% |
| 대검·전투도끼·전투망치 숙련 | `weapon:heavy` | +0 | -15% | +30% |

스킬 설명의 `적용 장비`에는 해당 카테고리의 모든 장비 이름을 표시합니다. 내부 스킬 ID와 효과 수치는 유지합니다.

각 숙련은 기존 6개 슬롯 중 1칸을 사용합니다. 전투·비전투에서 ON/OFF 전환은 즉시 처리하고 행동·예약·횟수를 소비하지 않습니다(전투당 제한 없음). 같은 ON 요청은 중복 적용하지 않습니다. ON/OFF 설정은 캐릭터별로 저장·복원되며 새 전투에서도 유지됩니다. 기존 저장의 전투 중 숙련 설정도 한 번 이관합니다. 평상시 능력치 표시에도 적용합니다. 매혹·지배 중에는 조작할 수 없습니다. 사망·장비 불일치·슬롯 해제 시 효과는 적용되지 않지만 ON/OFF 설정은 유지됩니다. 다시 조건을 만족하면 효과가 적용됩니다. 유지형 효과는 36종 Buff/Debuff가 아니므로 지속시간·INT·정화/해제 대상이 아닙니다.

무기와 갑옷 숙련의 명중·속도·피해 보정은 종류별로 합산합니다. 속도는 기존 DEX·갑옷·무기·상태에 따른 속도에 `(1 + 숙련 속도 합계)`를 곱하고, 준비도를 보존한 채 남은 행동 시간을 다시 계산합니다. 피해는 일반 공격과 무기 공격 스킬에 `(1 + 숙련 피해 합계)`를 곱합니다. 회복량·상태 지속시간·Raw 고정 피해에는 적용하지 않습니다. 전투 로그에 숙련 배율을 별도로 표시합니다.

`effect.type=equipmentMastery`, `equipmentSlot=weapon|armor`, 실제 `weaponCategory`/`armorCategory`에 대응하는 `category`, `accuracyBonus`, `actionSpeedRate`, `damageRate`, 선택적인 `defenseBonus`(생략 시 0)로 정의합니다. `defenseBonus`는 DEF에 직접 합산되며 능력치 상세의 장비 숙련 항목에 표시합니다. RES·WIL·방어도·디버프 지속시간은 바꾸지 않습니다. 기존 accuracyBonus 예시의 weaponCategories는 템플릿 ID 목록이므로 새 숙련의 카테고리 조건과 구별합니다.

## 자동·수동 스킬 모드

캔버스 아래 제목 버튼으로 전환합니다. 기본은 수동이며 모드는 캐릭터별로 저장되어 새 전투·저장 복원 후에도 유지됩니다. 자동 전환 시 기존 수동 예약을 비용 없이 취소합니다. 전환은 행동 준비도·사용 횟수를 바꾸지 않습니다.

자동 모드는 각 영웅 행동 시점에 장착된 사용 가능한 직접 스킬을 균등 추첨하여 한 번 발동합니다. 해당 행동의 일반 공격을 대체하며 후보가 없으면 일반 공격합니다. 회복 불필요·회복 차단·사용 횟수 소진·매혹/지배·비활성/미장착 스킬은 제외합니다. 공격 스킬은 기존 명중 및 상태 저항 판정을 그대로 사용합니다. 강화 중복이나 상대 저항을 예상하여 추가로 제외하는 별도 AI 규칙은 없습니다. 숙련 ON/OFF는 추첨 대상이 아니며 기존처럼 직접 조작합니다.

자동 모드의 전투 중 직접 스킬 수동 예약은 거부합니다. 비전투 회복은 기존 방식으로 사용할 수 있습니다. 오프라인에도 같은 서버 행동 처리와 게임 시간 규칙으로 작동합니다.

## 설명과 판정 로그

스킬 목록과 툴팁은 같은 효과 설명을 한 번만 표시합니다. 공격은 무기 판정·보너스·상태 판정·효과·시간·횟수 순서이며 숙련은 적용 장비와 0이 아닌 보너스만 표시합니다. 전투 로그는 무기 명중·피해 아래에 상태 판정과 적용/실패/저항/상쇄 결과를 별도로 기록합니다. 기존 스킬 ID·명칭·아이콘·전투당 제한·예약 방식은 유지합니다. 예시의 속임수 자원·소음·방해 조건은 이번 변경에 추가하지 않습니다.

## 정화·해제 제거 및 방어구 숙련 조정

정화(`purify`)와 해제(`dispel`)는 카탈로그·획득 목록에서 제거했다. 저장 불러오기 시 해당 소유 스킬·장착 슬롯·예약·사용 횟수·토글만 정리하며 다른 스킬과 진행 중 상태 효과는 보존한다. 기존 아이콘 파일은 사용하지 않는 아트 자료로 남긴다.

천옷 숙련은 **DEF +5만**, 경량은 **행동속도 +10%만**, 중형은 **+15%만**, 중장은 **+20%만** 부여한다. 방어구 숙련 피해 보정은 모두 0이며 무기 숙련은 유지한다.
