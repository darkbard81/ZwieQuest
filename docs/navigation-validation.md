# 경로 목적지 예약과 지도 화면 유지

## 동작

- 도달 가능한 표시 노드 선택은 기존 자동 이동을 유지합니다. 수동 방향 선택·귀환 시 기존 즉시 자동 이동은 종료됩니다.
- 지금 도달 불가능한 표시 노드는 `reservedRoute: { mapId, nodeId, startRun }`로 계정 상태에 저장합니다. 현재 모험의 길은 바꾸지 않고 다음 모험부터 따라갑니다. 해당 지역을 다음 출발 지역으로 지정하며, 예약 후 출발 지역을 따로 바꾸면 목적지는 보존하고 해당 지역에서 다시 도달 가능해질 때 따라갑니다.
- 예약은 패배·귀환·수동 우회·재접속·서버 재시작에도 유지합니다. 실제 목적지 도착 시 정리합니다. 이동 시작만으로 해제하지 않습니다. 출발점·지역 출구·막다른 길·보스 목적지도 도착 처리를 거칩니다.
- 새 목적지 선택이 이전 목표를 교체하며 해제 버튼은 즉시 목표와 예약을 모두 제거합니다. 지도 재생성 시 이전 지도의 목표를 제거합니다. 현재 위치 및 숨겨진 노드 선택 제한은 유지합니다.
- 구 저장에는 예약을 null로 추가하고 기존 즉시 목표는 보존합니다. 유효하지 않은 지도·노드·시작 회차의 예약은 제거합니다. SQLite 스키마 변경은 없습니다.
- 지도 버튼으로 열 때 현재 위치를 한 번 표시합니다. 열린 동안 현재 위치 표식·경로·상태는 갱신하고 스크롤과 배율은 유지합니다. 현재 위치·시작점 버튼은 명시적으로 화면을 이동합니다. 배율 변경은 보고 있던 화면 중앙을 기준으로 합니다.
