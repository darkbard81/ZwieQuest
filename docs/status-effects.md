# ZwieQuest — 능력치별 Buff / Debuff 3단계

ZwieQuest는 6개 기본 능력치마다 **3단계 강화(Inspiration)**와 **3단계 약화(Affliction)**를 정의합니다.

- **Buff:** 해당 능력치 +5와 단계에 따른 추가 효과를 적용합니다.
- **Debuff:** 해당 능력치 −5와 단계에 따른 추가 효과를 적용합니다.
- **2·3단계:** 일반적으로 이전 단계의 효과를 포함하며 추가 효과를 획득합니다. 각 단계에 효과가 직접 나열되어 있으면 해당 목록을 따릅니다.
- **상쇄:** 같은 능력치의 Buff와 Debuff는 단계와 관계없이 서로 제거합니다.

## 1. 능력치별 상태 효과

### STR / MIG — 완력 (Might)

| 단계 | Buff (강화) | Debuff (약화) |
| --- | --- | --- |
| 1 | **Strong (강력):** 완력 +5 | **Staggered (비틀거림):** 완력 −5 |
| 2 | **Tenacious (강인):** 1단계 효과 + 관통력 +2 | **Dazed (멍해짐):** 완력 −5, 관통력 −4 |
| 3 | **Energized (활력):** 2단계 효과 + 치명타 적중 시 적 방해(Interrupt: 행동속도 재카운트) | **Stunned (기절):** 완력 −5, DEF −10, 관통력 −4 |

### CON — 체질 (Constitution)

| 단계 | Buff (강화) | Debuff (약화) |
| --- | --- | --- |
| 1 | **Fit (건강):** 체질 +5 | **Sickened (병듦):** 체질 −5, 받는 회복량 −25% |
| 2 | **Hardy (튼튼함):** 1단계 효과 + 방어도(AR) +2 | **Weakened (쇠약):** 체질 −5, 받는 회복량 −50% |
| 3 | **Robust (강건):** 2단계 효과 + 3초마다 체력 10 회복 | **Enfeebled (극심한 쇠약):** 체질 −5, 회복 차단, 적대적 효과 지속시간 +50% |

### DEX — 민첩 (Dexterity)

| 단계 | Buff (강화) | Debuff (약화) |
| --- | --- | --- |
| 1 | **Quick (신속):** 민첩 +5 | **Hobbled (절뚝거림):** 민첩 −5 |
| 2 | **Nimble (날렵):** 1단계 효과 + 자신에게 들어오는 명중(Hit)의 25%를 빗맞음(Graze)으로 전환 | **Immobilized (이동불가):** 1단계 효과 + 피격 시 빗맞음(Graze)의 50%를 명중(Hit)으로 전환 |
| 3 | **Swift (쾌속):** 2단계 효과 + Interrupt 면역 | **Paralyzed (마비):** 2단계 효과 + 피격 시 명중(Hit)의 25%를 치명타(Crit)로 전환 |

### PER — 지각 (Perception)

| 단계 | Buff (강화) | Debuff (약화) |
| --- | --- | --- |
| 1 | **Insightful (통찰):** 지각 +5 | **Distracted (주의산만):** 지각 −5, DEF −10 |
| 2 | **Aware (경계):** 1단계 효과 + 빗맞음(Graze)의 50%를 명중(Hit)으로 전환 | **Disoriented (혼란):** 1단계 효과 + 행동시간 +50% |
| 3 | **Intuitive (직관):** 2단계 효과 + 명중(Hit)의 25%를 치명타(Crit)로 전환 | **Blinded (실명):** 2단계 효과 + 명중률 −10 |

### INT — 지능 (Intellect)

| 단계 | Buff (강화) | Debuff (약화) |
| --- | --- | --- |
| 1 | **Smart (총명):** 지능 +5 | **Confused (혼란):** 지능 −5 |
| 2 | **Acute (예리):** 1단계 효과 + 부여하는 Debuff 지속시간 +25% (별도 스킬 쿨다운 폐지에 따른 대체 효과) | **Charmed (매혹):** 1단계 효과 + 조작 불가, 일반 공격만 가능 |
| 3 | **Brilliant (영특):** 2단계 효과 + 6초마다 무작위 스킬 자원 복구(전투당 N회 제한이 있는 스킬 대상) | **Dominated (지배):** 2단계 효과 + 자기 자신에게 공격 |

### RES — 결의 (Resolve)

| 단계 | Buff (강화) | Debuff (약화) |
| --- | --- | --- |
| 1 | **Steadfast (굳건):** 결의 +5 | **Shaken (동요):** 결의 −5 |
| 2 | **Resolute (의연):** 1단계 효과 + 자신에게 적용된 Buff 지속시간 소모 속도 ×0.5 | **Frightened (공포):** 1단계 효과 + 자신에게 적용된 Buff 지속시간 소모 속도 ×2 |
| 3 | **Courageous (용맹):** 2단계 효과 + 다른 능력치 Buff의 적용 단계 +1 | **Terrified (극도의 공포):** 2단계 효과 + 다른 능력치의 Debuff에 취약(적용 단계 +1) |

## 2. Buff / Debuff 적용 규칙

| 상황 | 처리 방식 |
| --- | --- |
| 동일 능력치의 1단계 → 2단계 | 기존 상태를 2단계로 교체 |
| 동일 능력치의 3단계 → 1단계 | 기존 3단계 유지 |
| 동일 능력치의 Buff ↔ Debuff | 서로 상쇄, 두 상태 모두 제거 |
| 다른 능력치의 상태 | 동시에 적용 가능 |
| Debuff 저항(Resistance) | 적용 단계 −1, 1단계는 무효 |
| Debuff 취약(Weakness) | 적용 단계 +1, 최대 3단계 |
| 동일 단계 재적용 | 남은 지속시간과 새 지속시간 중 긴 값 유지 |

예를 들어 STR 3단계 기절(Stunned) 상태라도 STR 1단계 강화인 Strong을 적용하면 기절을 제거할 수 있습니다. Strong 자체는 남지 않습니다.

## 3. 시스템의 핵심 특징

ZwieQuest의 3단계 상태 시스템은 단순히 능력치를 단계별로 더 크게 증감시키는 방식이 아닙니다.

모든 단계의 기본 능력치 증감은 **±5로 동일**하며, 단계가 높아질수록 전투 규칙에 직접 영향을 주는 특수 효과가 추가됩니다.

따라서 상태의 위력은 능력치 보정량보다 명중 등급 변환, 관통력, 행동 제한, 자원 회복, 전투 제어 같은 추가 효과에 의해 결정됩니다. 이는 능력치 성장과 상태이상 시스템을 분리하면서도 서로 연결할 수 있는 구조입니다.


## 4. 구현 세부 규칙

- 정의 원본은 `data-templates/status-effects.json`, 처리기는 `src/status-effects.js`입니다. 36종 모두 처리하며 첫 18개 스킬이 이 중 일부를 직접 부여합니다.
- 모든 지속시간은 발동 시 시전자 유효 INT를 적용합니다: `round(기본 밀리초 × max(0.25, 1 + INT × 0.05))`. 시전 자체가 올리는 INT는 해당 시전 시간에 소급하지 않습니다.
- Acute의 부여 약화 시간 ×1.25와 Enfeebled 대상의 적대적 효과 시간 ×1.5는 위 결과에 곱합니다. 회복 차단은 직접 회복과 주기 회복에 적용합니다.
- Resolute의 Buff 소모 ×0.5는 자기 자신을 포함합니다. Frightened는 Buff만 ×2로 소모하며 Debuff 시간은 그대로입니다. 적용 중인 상태의 남은 시간을 매번 재산정하지 않습니다.
- Courageous/Terrified는 자신 외 능력치에 새로 적용하는 상태의 단계만 변경합니다. 이미 걸린 상태는 소급 승격하지 않습니다. RES 자신에게 단계 보정을 반복하지 않습니다.
- 저항·취약 보정 → 0단계 면역/3단계 상한 → 반대 효과 상쇄 → 같은 방향 단계/시간 비교 순입니다. 저항으로 무효인 적용은 기존 강화와 상쇄하지 않습니다. 동일 단계 갱신은 주기 효과의 다음 발동 시간을 초기화하지 않습니다.
- 명중 등급 전환은 원래 판정을 기준으로 한 단계만 가능합니다. 피격 Hit→Graze 방어가 먼저 적용되고, 그 외 같은 방향 전환 확률은 `1 − (1−공격자 확률) × (1−방어자 확률)`입니다. Graze→Hit→Crit 연쇄 변환은 없습니다.
- Energized는 적에게 치명타 시 그 적의 준비도를 0으로 되돌립니다. Swift는 이 초기화에 면역입니다. Stunned/Immobilized/Paralyzed는 이름으로 추가 행동 금지를 부여하지 않고 표의 효과만 적용합니다.
- Charmed 중에는 스킬 사용·장비/스킬 장착 변경·능력치 배분이 차단되며 일반 공격만 합니다. 이미 예약한 스킬도 실행 시 취소되고 횟수를 쓰지 않습니다. Dominated는 해당 일반 공격의 대상을 자기 자신으로 바꿉니다. 몬스터에게도 동일하게 적용됩니다.
- Robust는 3게임초마다 10 HP, Brilliant는 6게임초마다 현재 장착된 제한 스킬 중 소모 횟수가 있는 하나를 무작위로 골라 1회 복구합니다. 회복량은 받는 회복 보정 후 내림, 최대 HP 이하입니다. 복구할 대상이 없으면 아무것도 하지 않습니다. 주기는 INT로 늘리지 않으며 효과의 전체 지속시간만 늘립니다.
- 같은 시각에는 상태 만료를 주기 발동 및 행동보다 먼저 처리합니다. 만료 시각과 주기 발동 시각이 같으면 마지막 주기는 발생하지 않습니다.
- 최대 HP가 줄면 현재 HP를 새 상한까지 낮추며, 증가해도 자동 회복하지 않습니다. 유효 최대 HP는 최소 1입니다. 기본 능력치와 장비 원본은 변경하지 않습니다.
- 상태·남은 게임 시간·다음 주기까지의 시간은 전투에 저장합니다. 온라인/오프라인 배속, 큰 틱, 재시작에도 같은 순서로 진행하며 서버 정지 시간은 보상하지 않습니다. 사망·전투 종료에는 모두 제거합니다.
- `statusResistance: {resistance: {DEX: 1}, weakness: {CON: 1}}` 형식의 전투원 보정도 처리합니다. 첫 목록에는 영구 저항 장비를 추가하지 않았습니다.
