# 지역 설정

`data-templates/regions.json`이 지역 설정의 단일 원본입니다. 서버 시작 시 읽으며 변경 후에는 서버 재시작과 브라우저 새로고침이 필요합니다.

- `name`, `subtitle`, `tag`: 지역 이름, 설명, 화면 태그.
- `canvas`, `route`: 모험 화면과 경로지도 배경의 `/assets/` 경로.
- `depth`: 새 맵의 마지막 노드 깊이. 현재 여섯 지역 모두 **10**입니다.
- `minLevel`, `maxLevel`: 일반 몬스터의 무작위 레벨 범위. 시작 맵 드롭다운의 레벨 표기도 이 값을 사용합니다.
- `excludedDamageTypes`: 일반 몬스터 및 보스 후보에서 제외할 공격 속성.
- `bossDamageType`: 보스 후보의 필수 공격 속성. 보스가 있는 지역에 설정합니다.
- `deadEnds`: 마지막 깊이에 배치하는 막다른 길 수. 중간 경로의 무작위 막다른 길은 별도로 생성됩니다.
- `exits`: 마지막 깊이에서 연결할 지역 ID 목록.
- `boss`: 마지막 깊이에 배치할 보스 노드의 이름. 보스가 없으면 `null`입니다. 실제 전투 개체는 `bossDamageType` 조건으로 추첨합니다.

새싹마을은 마지막 깊이에 막다른 길 5개와 출구 5개를 배치합니다. 다른 다섯 지역은 보스 한 개를 배치하고, 이진 분기를 유지하기 위해 보스 옆에 막다른 길 한 개를 자동 추가합니다.

깊이를 줄일 때도 마지막 목적지들을 모두 담을 수 있어야 합니다. 현재 마을은 최소 깊이 4, 보스 하나만 있는 지역은 최소 깊이 1입니다. 생성기는 깊이 10의 기존 분기 규칙을 유지하며, 더 긴 맵에서는 중간 폭을 유지한 뒤 마지막 구간에서 줄입니다. 깊이 0~4의 노드 상한은 `2 ** 깊이`입니다. 그 이후 상한은 마지막 목적지 수(최소 10)와 남은 깊이에 따라 결정됩니다.

이미 저장된 맵은 설정의 깊이가 바뀌어도 경로·탐험·진행 상태를 보존합니다. 변경된 깊이와 출구는 신규 계정의 맵 또는 명시적으로 재생성한 맵에 적용됩니다. 새 지역을 추가하면 기존 계정에도 새 지역 맵을 생성해야 하므로, 관리자 본인 지도 재생성이나 별도 저장 데이터 이전이 필요합니다. 기존 `village`, `volcano`, `snow`, `desert`, `beach` ID는 변경하지 마세요.

`data-templates/encounters.json`에는 공통 보상 규칙만 남습니다. `src/monsters.js`의 `ENCOUNTER_CONFIG.regions`는 호환성을 위해 이 단일 원본을 참조하며 별도 설정이 아닙니다.

브라우저의 `public/regions.js`는 설정을 직접 보관하지 않습니다. 서버의 읽기 전용 `GET /api/regions`에서 이름·배경·깊이·레벨 범위만 읽습니다. 출구와 보스 구성은 이 응답에 포함하지 않습니다. 렌더러의 지역 배경 목록도 이 설정으로 생성합니다.

## 오래된 숲

`old_forest`: 레벨 5–20, 깊이 10. 새싹마을에서 연결되며 처음 입장하면 기존 체크포인트 규칙대로 여관 출발 지역에 추가된다. 배경과 경로지도는 기존 `public/assets/forest.png`를 활용한다. 새 삽화 생성은 하지 않았다.

기존 계정 로드 시 숲 지도만 새로 만들고, 마을의 마지막 막다른 길 한 개를 출구로 바꾼다. 기존 노드 ID·연결·탐험 기록·전투는 유지한다. 다른 지도 전체를 재생성하지 않는다. 이 신규 지역은 위의 일반적인 수동 지도 재생성 안내와 달리 자동 이관한다.

선택적 `bossMonsterId`는 속성 조건과 함께 보스 종을 제한한다. 오래된 숲은 `arachne` / `corrosion`으로 부식 아라크네가 보스이며 기존의 캐릭터 동레벨·전설 장비 규칙을 따른다.
