## 무손실 검증

`cwebp 1.6.0 -lossless -q 100 -m 6 -exact -metadata all`을 사용했다. `-q 100`은 이 무손실 모드에서 압축 노력에 관한 설정이며 손실 품질 설정이 아니다. `-exact`로 완전히 투명한 픽셀의 RGB도 유지했다.

42개 전부 원본과 WebP를 RGBA로 디코딩해 모든 픽셀의 네 채널이 정확히 같은지 검사했다. RGB·알파 차이 0, 크기 변경 0. 원본과 출력의 파일 SHA-256, 공통 디코딩 RGBA SHA-256, 파일 크기는 `public/assets/lossless-webp-manifest.json`에 기록했다.

- 캐릭터당 6장, 각 4096×1536, 512×512 셀 24개, 256×256 표시 유지.
- 프레임 좌표·선택·재생 시간·배치·전투 처리 유지.
- `sprite.json`의 시트 참조와 캐시 버전을 갱신하고 지역/여관 배경 및 공유 CSS 배경 참조도 WebP로 변경.
