# 전투 규칙 v4 — 캐릭터별 성장과 수동 스킬

무기·방어 규칙은 이슈 #2를 기반으로 유지하며, 자동 전술은 수동 스킬로 교체했다.

## 장착 및 명중 판정

클래스는 없으며 모든 캐릭터가 무기 15종과 방어구 9종을 장착한다. 장비 한 개는 한 캐릭터만 장착한다. 생성 시 일반 단검과 가죽갑옷을 지급한다. 무기 드롭 후보는 15종 전체다. 기존 아이템의 `classId`는 저장 호환용 기록으로 남지만 장착 제한으로 사용하지 않는다.

| 명중 대상 | 무기 |
|---|---|
| DEF(방어) | 숏소드·롱소드·대검·손도끼·전투도끼·할버드 |
| REF(반사) | 단검·레이피어·창 |
| FOR(인내) | 메이스·전투망치 |
| WIL(정신) | 화염·냉기·번개·부식 지팡이 |

신규 무기는 `hitDefense`를 저장한다. 이전 카테고리 장비는 templateId로 판정 대상을 찾고, 카테고리 이전 구형 검/지팡이는 DEF/WIL로 취급한다. 무기 해제 시 맨손은 DEF, 기본 피해 1이다. 클래스·추가 속성 접두사는 명중 대상을 바꾸지 않는다. 현재 몬스터 몸통 박치기는 DEF를 공격한다.

피해 타입과 명중 대상은 독립이다. 피해 타입은 최저 유효 AR 선택에만 사용한다. 무기 범위·등급 보정·d20·STR·관통 공식은 유지한다. 신규 INT 기반 무기 피해 가산은 없다. 구 무기의 피해는 무기 계열에 해당하는 기존 기본 피해(검 16, 지팡이 20) + 저장된 power를 사용해 전직 때문에 바뀌지 않게 했다.

## 캐릭터 능력치

6 기본 능력치는 투자값 0에서 시작한다. 누적 자유 포인트는 `10 + floor(level / 2)`, 유효 능력치는 투자값 + 장비 보너스다. 장비 페널티는 음수를 허용한다.

- 레벨 보너스 `LB = floor((level - 1) / 3)`.
- `ACC = 10 + PER + LB + 장비 ACC`.
- `DEF = 10 + RES + LB + 장비 DEF`.
- `REF = 10 + DEX + PER + LB + 장비 REF`.
- `FOR = 10 + STR + CON + LB + 장비 FOR`.
- `WIL = 10 + INT + RES + LB + 장비 WIL`.
- `maxHP = 10 + 5 × (level - 1) + 5 × CON + 장비 HP`.

기존 명중 판정 `d20 + ACC` 대 `10 + 대상 방어`는 유지한다. 방어 기본값 10과 판정의 상수 10은 서로 다른 항이다. 몬스터 공식과 무기 판정 대상은 변경하지 않는다. 신규 무장 단검 ACC +2, 가죽갑옷 DEX −1이 있으므로 미배분 캐릭터의 실제 ACC는 12, REF는 9다.

## 3 AP와 라운드

아군 턴 + 적군 턴이 1라운드다. 전투 시작 때 장비 DEX를 포함해 선공을 정하고 전투가 끝날 때까지 유지한다. 양쪽 모두 1 AP 일반 공격을 자동으로 3회 실행하며 실제 연속 공격에만 0/−5/−10 명중 페널티를 적용한다. AP는 이월되지 않는다.

자동 전술 선택·예약·버프는 제거했다. 수동 스킬은 자기 턴에 1개만 사용할 수 있고 AP를 소모하지 않는다. 모든 캐릭터는 회복을 기본 습득한다. 수치와 목록은 `data-templates/skills.json`, 상세 공식·장착·저장·이관 정책은 [스킬 규칙](skills.md)을 따른다.

## 피해

`floor(범위 정수 × (1 + 등급 피해율) × (1 + 0.05×STR) × 명중 단계 배율 × 관통 배율)`

중간 내림은 없다. Raw는 빗나감이면 0, 그 외 저장된 고정 피해로 AR/PEN·STR·치명타·등급 보정을 무시한다. 과거 전투 로그는 당시 계산식 그대로 표시한다.

## 기존 갑옷 포함 DEX 이관

후속 액세서리 변경으로 구형 수호자의 외투는 이제 신규 가죽 갑옷/로브로 교체한다. 아래 DEX 이관의 기타 수치 보존은 카테고리 갑옷에 적용한다. 최신 전환 규칙은 [액세서리 규칙](accessory-rules.md)을 따른다.

| 카테고리 | DEX |
|---|---:|
| 천옷/로브, 카테고리 이전 구형 수호자의 외투 | 0 |
| 가죽·덧댄·생가죽 | −1 |
| 사슬·비늘·흉갑 | −2 |
| 브리건딘·판금 | −3 |

기존 갑옷에도 위 값을 적용하며 `dexRulesVersion: 2`로 중복 이관을 막는다. AR·HP·등급·특수 옵션·가격·UUID는 그대로 둔다. 등급이 올라가도 DEX 패널티는 커지지 않는다. 장비 DEX는 기존 REF 공식의 DEX 항과 선공에 반영되며 ACC를 바꾸지 않는다. 음수 DEX를 허용한다. 클래스 기본 능력치와 클래스 숙련은 제거했으며 아래 공통 성장식을 사용한다.

## 저장·보상·회복

진행 중 전투는 저장된 선공·행동자·AP·공격 횟수·HP·몬스터를 유지하고 전술 효과만 제거한다. 전투별 스킬 사용 여부는 현재 전투에, 습득·장착·쿨다운은 해당 캐릭터에 저장한다. 기존 HP는 새로운 최대 HP를 넘는 경우에만 제한한다. 기본 능력치는 `snapshot.stats`와 `snapshot.combatStats`에 같은 값으로 제공한다.

전투 승리(보스 포함)마다 25% 확률로 무기·방어구·부적 중 하나를 동일한 확률로 지급한다. 보물 상자는 금화만 지급한다. 장비 등급·특수 옵션·기존 이미지·몬스터 수치는 유지한다.

전투 승리·보물·레벨 상승으로 HP는 회복되지 않는다. 여관에서 다음 여행을 시작할 때 최대 HP로 회복한다. 모험 중 회복은 수동 회복 스킬을 사용한다.

## 검증

수동 스킬 검증은 `tests/skills.test.js`와 `tests/skills-http.test.js`, 무기·일반 턴·갑옷 검증은 `tests/combat-turns.test.js`에 있다. 이전 전술 비교 시뮬레이션 스크립트는 일반 공격만 비교하도록 변경했다. 기존 전술 승률 기록은 현재 규칙의 결과로 사용하지 않는다.
