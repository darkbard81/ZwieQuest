# 튜토리얼 보물

튜토리얼 이미지는 원본 PNG를 보존하고 `cwebp -q 90`으로 **손실 WebP 품질 90**으로 변환하여 `public/assets/treasures/`에 배포합니다. 해상도·비율은 원본 그대로 유지합니다. 품질 90은 인코더 설정이며 손실률 10%를 의미하지 않습니다. 기존 환영 타이틀은 무손실 WebP를 유지합니다.

## 01. 게임의 소개

- 원본: `evidence/tutorial/zwiequest-introduction-4panel.png`
- 배포: `public/assets/treasures/tutorial-introduction-v1.webp`
- 해상도: 1448×1086, 4:3
- 인코딩: `cwebp -q 90`, VP8 손실 압축
- 용량: 3,037,314 bytes → 544,440 bytes
- 상품 ID: `tutorial-introduction`, 이름: `01. 게임의 소개`, 가격: 0 G

가방 → 보물에서 무료로 소장하고 상자 아이콘으로 4컷 만화를 엽니다. 계정 공용 소장품이며 장착·판매·일괄판매 대상이 아닙니다.

## 표시 순서

`src/treasures.js`의 `TREASURES` 각 항목에 `id_sort`를 10 단위로 지정합니다. 현재 `환영합니다`는 10, `01. 게임의 소개`는 20입니다. 다음 튜토리얼은 30, 40 순으로 추가합니다.

보물 탭은 소장품과 미구입 상품을 합쳐 `id_sort` 오름차순으로 표시합니다. 구매 순서와 관계없이 같은 위치를 유지합니다. 기존 소장품도 스냅샷을 만들 때 최신 상품 정의에서 정렬값을 읽으므로 저장 데이터 수정 없이 반영됩니다. 상품 정의 변경 후 서버를 재시작하고 브라우저를 새로고침합니다.
