# UI 아이콘

사용자가 제공한 21개 WebP를 SVG 경로로 벡터화했습니다. 원본은 `source/`, 원본 해시·크기·표시명·색상은 `manifest.json`에 있습니다. 런타임 결과는 `public/assets/ui-icons/`에 있습니다.

- 능력치 13개: 힘, 체질, 민첩, 통찰, 지능, 결의, 명중, 방어도, 레벨 보너스, 회피, 반사, 인내, 의지.
- 피해 유형 8개: 베기, 관통, 부수기, 소각, 동결, 충격, 부식, 고정.
- 관통력(PEN) 아이콘은 요청에 따라 비워 둡니다. 피해 유형 관통(pierce)과 구분합니다.
- 피해 색상은 `public/style.css`의 `--damage-color`에서 읽습니다. 빨강, 보라, 갈색, 주황, 파랑, 노랑, 녹색, 회색 순입니다.
- 작은 원본의 알파 윤곽을 확대해 곡선으로 추적하고 명암을 유지합니다. 어두운 단색 능력치 아이콘은 어두운 UI에서도 보이도록 밝기를 보정합니다.
- SVG에는 비트맵 이미지나 외부 참조를 넣지 않습니다. UI는 아이콘과 한글 이름을 함께 표시합니다.
- 저장 데이터의 영문 키는 유지합니다. 옛 전투 기록의 피해 유형 명칭은 표시 시 새 명칭으로 변환하며, 저장된 장비 고유 이름은 변경하지 않습니다.

## 재생성

게임 실행에는 Python 도구가 필요하지 않습니다. 아이콘을 다시 제작할 때만 별도 가상환경을 사용합니다.

```sh
python3 -m venv /tmp/zwiequest-svg-env
/tmp/zwiequest-svg-env/bin/pip install Pillow==13.0.0 vtracer==0.6.15
/tmp/zwiequest-svg-env/bin/python tools/build-ui-icons.py
```
