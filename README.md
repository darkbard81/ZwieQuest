# ZwieQuest

작은 창에서 지켜보는 자율 모험 RPG. 여관에서 이름과 외형으로 캐릭터를 생성하고, 갈림길과 장비에 개입하거나 스스로 이어지는 모험을 관찰합니다.

## 실행

Node.js 24 이상이 필요합니다. 의존 라이브러리는 프로젝트에 포함되어 있어 `npm install`이나 API 키가 필요하지 않습니다.

```bash
git clone https://github.com/darkbard81/ZwieQuest.git
cd ZwieQuest
PORT=4317 PUBLIC_ORIGIN=http://127.0.0.1:4317 npm start
```

브라우저에서 **http://127.0.0.1:4317** 을 열고 회원가입 → 클래스 선택을 진행하세요. 처음 실행할 때 사용자 비밀번호나 계정은 미리 만들어 두지 않습니다. `Ctrl+C`로 서버를 정상 종료할 수 있습니다.

- 서버가 실행 중이면 브라우저 종료·로그아웃 후에도 모험이 진행됩니다.
- Steam Deck 절전·전원 종료 또는 서버 종료 중에는 게임이 멈춥니다. 재시작 때 중단 시간을 사후 보상하지 않습니다.
- 회원가입은 이 서버의 아이디·비밀번호 방식입니다. ChatGPT 로그인은 승인된 연동 자격이 없어 연결하지 않았습니다.
- 환경변수 없이 `npm start`를 실행하면 기존 배포 설정인 `127.0.0.1:3011`과 `https://card.krdp.ddns.net` 출처를 사용합니다. 다른 환경에서는 `PUBLIC_ORIGIN`을 실제 주소로 지정하고 HTTPS 역방향 프록시를 별도로 구성하세요. HTTPS 주소를 요청 출처로 허용하고 세션 쿠키에 Secure 속성을 적용합니다.
- `PORT`, `HOST`, `PUBLIC_ORIGIN` 환경변수로 시작 설정을 덮어쓸 수 있습니다. 예: 로컬 개발은 `PORT=4317 PUBLIC_ORIGIN=http://127.0.0.1:4317 npm start`.

## 플레이

마을에서 다른 지역으로 넘어갈 때는 여관에 들르지 않고 해당 지역의 첫 갈림길로 이어집니다. 현재 체력과 여행 회차를 유지하며, 지역 도착 자체로 휴식하거나 새 여행을 시작하지 않습니다.

HOME → 마을의 전진 경로 → 지역 출구 → 해당 지역의 전진 경로 → 지역 보스 → HOME입니다. 마을과 네 지역은 깊이 10의 저장된 맵을 사용합니다. 새 마을 맵은 깊이 10의 목적지 10개(막다른 길 6개, 홍련 분화구·백야 설원·산성 호수·낙뢰 고원 출구 4개)를 가지며, 각 지역은 깊이 10의 보스 한 마리를 유지합니다. 모든 맵은 같은 생성 규칙을 사용합니다. 깊이 0~4의 최대 노드 수는 `2 ** 깊이`(1→2→4→8→16), 깊이 5~10은 `30 - 2 * 깊이`(20→18→16→14→12→10)입니다. 막다른 길도 전체 노드 수에 포함하며, 깊이 0~3의 모든 노드는 두 갈래로 분기합니다. 초반 분기 후에는 다음 깊이 상한 안에서 이어질 가지 수와 위치를 무작위로 정하고, 나머지는 막다른 길로 만듭니다. 중간 경로가 한 줄로 급격히 줄지 않도록 가능한 분기 수의 절반 이상을 유지하며, 깊이 9에서는 정해진 깊이 10 목적지 수에 맞춰 마무리합니다. 지역 보스 옆에는 막다른 길 한 개가 있습니다. 모든 마지막 노드는 출발점에서 도달 가능합니다. 모든 막다른 길·패배·보스전 종료 후에는 집(HOME)으로 돌아갑니다. 체크포인트는 계정별로 중복 없이 기록하며, 경로 지도의 다음 출발 지역 목록을 해금합니다. 초기 마을과 통과한 지역 중 선택한 곳의 출발점에서 다음 HOME 출발을 시작합니다. 진행 중인 모험에는 영향을 주지 않고, 귀환은 항상 마을 여관입니다.

- **화면 안의 윤곽 화살표 / 방향키:** 서로 다른 앞으로 가는 길입니다. 모든 맵은 합류 없이 갈라지는 이진 트리이며, 이전 깊이로 돌아가지 않습니다. 오른쪽은 전투 위험과 보상이 조금 높습니다. 경로 지도에서 탐험한 곳과 현재 위치를 볼 수 있습니다. 갈림길에서는 캔버스 안에 큰 SVG 화살표 두 개만 표시합니다. 단계·제한시간·추가 안내 라벨은 표시하지 않습니다. 온라인 9초, 오프라인 4.5초 동안 선택하지 않으면 서버가 자동 선택합니다. 왼쪽은 측면 걷기를 좌우 반전하고, 오른쪽은 원래 방향으로 걷습니다. 두 선택 모두 경로상 전진합니다.
- **경로 지도:** 시작점이 위에 놓이며 탐험한 경로만 펼쳐집니다. 노드는 `출발점`, `1-1`, `2-4`처럼 표시하고, 번호는 저장된 전체 트리에서 같은 깊이의 왼쪽부터 매기므로 탐험 범위가 달라져도 유지됩니다. 탐험한 갈림길의 왼쪽·오른쪽은 표시하되, 아직 가지 않은 곳은 모두 동일한 미탐험 표시로 가립니다. 목적지 이름·종류와 그 이후의 분기는 도착하기 전까지 숨깁니다. 탐험 기록은 지역별로 저장되어 귀환·재접속 후에도 유지됩니다. 기존 저장은 남아 있는 경로·현재 위치·체크포인트 기록에서 확인 가능한 탐험만 복원합니다. 왼쪽 선택은 왼쪽 아래, 오른쪽 선택은 오른쪽 아래로 이어지며 모든 연결은 수평·수직선입니다. 시작점·현재 위치 이동과 50~125% 배율, 가로·세로 스크롤을 지원합니다. 다섯 지역 모두 ImageGen으로 제작한 1536×1024 탑뷰 SD 애니메이션 배경을 적용합니다. 기존 지도 구조·탐험·체크포인트는 유지하며 저장된 지역명만 현재 이름으로 갱신합니다.
- **출발 지역·자동 이동:** 경로 지도에서 초기 마을 또는 통과한 체크포인트 지역을 다음 출발 지역으로 선택합니다. 선택은 계정에 저장되며, HOME에서는 그 지역 지도를 미리 표시합니다. 현재 위치에서 앞으로 이어지는 표시된 노드를 클릭하거나 키보드로 선택하면 목표까지 갈림길을 자동 선택합니다. 전투·보물을 처리한 뒤 이어가며 목표 도착, 수동 방향 선택, 해제 버튼 또는 귀환 시 종료합니다. 미탐험 노드의 종류·그 이후 경로는 공개하지 않으며, 숨겨진 목적지나 뒤쪽·다른 가지로의 이동은 허용하지 않습니다.
- **랜덤 인카운터:** 일반 경로 도착마다 한 번 판정합니다. 기본값은 전투 20%, 보물 5%, 통과 75%로 전체 발생 확률은 25%입니다. 관리자 설정의 확률관리 탭에서 두 손잡이 슬라이더로 조절하고 확정하면 모든 계정의 다음 추첨부터 적용되며, 재시작 후에도 유지됩니다. 같은 노드를 다시 방문해도 새로 판정하며, 막다른 길·지역 출구·보스는 고유 동작을 유지합니다. 저장된 전투·보물 처리 중 재접속하면 다시 판정하지 않습니다.
- **기존 지도 이전:** 버전 1 저장은 기존 노드·목적지·현재 경로·전투·타이머·체크포인트 이력을 보존하며 버전 2 트리로 한 번 이전합니다. 같은 자식으로 합류하던 중복 간선만 막다른 길로 바꾸므로, 이전된 맵에는 새 맵보다 막다른 길이 많을 수 있습니다. 생성 규칙 버전(generationVersion: 4)은 저장 형식 버전과 별도로 기록합니다. 기존 버전 2 지도는 재생성하지 않으며, 새 생성 규칙은 신규 지도와 명시적으로 재생성한 관리자 지도에 적용합니다. 기존 고정 보물·전투 배정은 제거하되 진행 중인 전투·보상은 유지합니다. 보스 수와 지도 구조는 바꾸지 않습니다.
- **가방:** 현재 캐릭터 장착품 → 다른 캐릭터 장착품 → 미장착품 순서로, 각 그룹은 희귀도가 높은 순서로 표시합니다. 일반 일괄 판매는 필터와 관계없이 모든 캐릭터에서 미장착인 일반 등급만 판매합니다. 전투·보스 처치와 보물상자의 획득 확률은 동일하며 기본 25%입니다. 성공하면 무기·방어구·액세서리·스킬 중 하나를 기본 1:1:1:1로 추첨합니다. 관리자 설정의 확률관리에서 획득 확률과 종류별 비율을 변경할 수 있습니다. 스킬은 현재 캐릭터의 미습득 대상만 지급하며 모두 배웠으면 해당 추첨의 추가 지급은 없습니다.
- **장착·해제·판매:** 여행·전투를 멈추지 않습니다. 장착품은 해제 후 판매할 수 있습니다. 변경 뒤의 공격부터 새 능력치가 적용됩니다.
- **전투·수동 스킬:** 일반 공격은 각 전투원의 DEX 기반 행동속도와 독립 준비도로 자동 실행합니다. 턴·라운드·3 AP와 연타 명중 페널티는 없습니다. 회복은 전투당 최대 2회 사용하며 남은 횟수를 표시합니다. 모든 캐릭터가 회복 스킬을 배우며 가방에서 최대 6개를 장착합니다. 전투 중 직접 스킬을 선택하면 다음 영웅 행동에 일반 공격 대신 발동하도록 1개 예약합니다. 예약 시에는 비용을 소비하지 않으며 실제 발동 때 사용 횟수를 적용합니다. 별도 쿨다운은 없습니다. 18개 기본 스킬과 36종 상태 효과를 지원하며 모든 지속시간에 INT를 적용합니다. 스킬 목록·수치·전투/비전투 구분·횟수 제한·직접/유지형 구분은 `data-templates/skills.json`, 관리 방법은 [스킬 문서](docs/skills.md)를 참고하세요. 자동회복은 여관에서 여행을 시작할 때만 적용됩니다.
- **여관·캐릭터:** 계정당 최대 3명을 이름과 외형으로 생성하고 한 명만 출전합니다. 외형은 능력치와 무관합니다. 성장·HP·장비·습득 스킬은 캐릭터별로 저장합니다. 소지품·금화·지도·경로는 계정 공용이며 장비 하나는 한 캐릭터만 장착합니다. 관리 중에는 자동 출발이 멈추며, 관리 완료 후 모험의 창에 나란히 Idle로 표시된 캐릭터를 클릭·터치하거나 키보드로 선택하면 해당 캐릭터로 즉시 출발합니다. 여관 버튼은 캐릭터 관리만 표시합니다. 캐릭터가 없으면 출발하지 않습니다. 자세한 규칙은 [캐릭터 시스템](docs/characters.md)을 참고하세요.
- **안전영역·탭 배치:** 왼쪽은 512×384 캔버스(기존 렌더링 해상도 유지), 오른쪽은 모험가·가방·도감·로그 탭입니다. 수동 스킬 아이콘은 모험의 창 아래에 표시합니다. 상태 효과는 캔버스 왼쪽(모험가)·오른쪽(몬스터)에 세로로 배치하고, 시계 방향 음영과 상태명·잔여 시간 툴팁을 제공합니다. 각 탭은 내부 스크롤됩니다. 완료한 여행·승리·보물 집계는 로그 상단에, 보유 금화는 가방에 표시합니다. 안전영역을 제외한 공간에 정보창을 맞추고, 좁은 화면에서는 세로로 배치합니다. 로그는 최신 기록이 아래에 쌓이며 이전 기록을 읽는 동안 위치를 유지합니다. 다른 탭에서 새 기록이 도착하면 로그 탭에 표시합니다. 로그 탭을 열 때는 항상 마지막 기록으로 이동하며 시분초는 표시하지 않습니다. 새 전투 기록은 공격자·대상·결과와 능력치 태그를 사용한 판정·피해 계산 설명으로 표시합니다.
- **자유 창:** 제목 표시줄 드래그, 최소화, DOM 창 크기 조절, 최소화 시 헤더만 표시·복원 시 기존 크기 유지, 화면 너비별 로컬 배치 저장, ‘창 정렬’로 기본 배치를 복원합니다. 가로 배치의 게임 화면은 512×384 CSS 픽셀이며, 세로 배치는 가용 너비에 맞춰 4:3 비율로 표시합니다.
- **진행 배율:** 온라인 1배, 오프라인 2배입니다. 이동·갈림길 선택 대기·전투 행동·보상·귀환·여관 대기에 같은 배율을 적용합니다. 개별 기본 행동 간격은 게임 시간 2.2초이며 속도는 `max(1, 100 + DEX × 5) × (1 − 갑옷 패널티)`입니다. 방어구는 DEX 대신 0/10/30/50% 속도 패널티를 적용합니다. 서버 틱(200ms)마다 도래한 행동을 시간순으로 처리하고 초과 경과시간을 보존합니다. 상태 지속시간과 주기 효과도 같은 게임 시간을 사용합니다.
- **접속 상태:** 수동 자리 비우기 버튼은 제공하지 않습니다. 접속 종료 시 서버가 온라인·오프라인 진행을 판단하며, 다른 탭이 연결 중이면 온라인으로 유지됩니다. 로그아웃은 현재 세션을 만료시킵니다.

## 구조와 저장

- `src/maps.js`: 목적지 배치→도달 경로 확보→추가 분기의 공통 맵 생성.
- `src/game.js`: 서버 소유 모험 상태, 사건, 명령, 보상, 인벤토리.
- `src/characters.js`: 캐릭터 UUID·소유권·성장 포인트·기존 클래스 저장본 이관. `characters[]`가 유일한 캐릭터 저장 원본이며 `activeCharacterId`로 출전 캐릭터를 선택합니다.
- `src/combat.js`: d20 성공 단계, 자연 1/20, PEN−AR, 최종 피해 버림, 능력치별 방어 계수와 파생 능력치(레벨 보너스 없음).
- `src/auth.js`: 인증 제공자 경계. 로컬 가입/로그인, scrypt 해시, 무작위 세션 발급/검증/폐기.
- `src/server.js`: HTTP/SSE, 사용자별 진행 스케줄러와 SQLite 트랜잭션.
- `public/render.js`: PixiJS 8.21 2D 렌더러. WebGL 지원 환경은 Pixi WebGLRenderer, 미지원 환경은 공식 Pixi CanvasRenderer를 사용합니다.
- `public/appearances.js`: 서버·클라이언트 공용 외형 목록. `appearanceId`는 그림만 선택하며 성장/능력치와 연결하지 않습니다.
- `public/inn-view.js`: 여관의 Idle 외형 목록과 배속을 반영한 출발 카운트다운.
- `public/tabs.js`: 모험가·가방·로그 탭 전환, 선택 탭 저장, 방향키·Home/End 접근성.
- `public/windows.js`: 최초 Grid → 자유 좌표 전환, 드래그·최소화·저장·복원.
- `config.json`: 시간·보상·장비·선공 및 공통 캐릭터 HP/ACC/4방어 기본값. 기본 HP 10, 레벨당 HP +5, 기본 ACC와 4방어 각각 10입니다.
- `data/zwiequest.sqlite`: 계정·세션·사용자별 현재 상태·사건·중복 요청 기록. 백업할 때 서버를 정상 종료한 뒤 `data/` 전체를 보관하세요.

모든 변경 명령은 사용자 세션에서 소유자를 얻으며 클라이언트의 사용자 ID·가격·피해·보상을 신뢰하지 않습니다. 상태·아이템·금화·새 사건·성공 요청 ID를 한 SQLite 트랜잭션으로 확정합니다. SSE는 확정 후의 현재 스냅샷과 최근 기록을 전송하며, 브라우저가 게임 결과를 계산하지 않습니다. 장기 상세 로그는 최근 약 5,000개로 정리하지만 누적 통계와 아이템은 유지됩니다.

## 자산

추가 맵에 사용하는 배경 5장(새싹마을·홍련 분화구·백야 설원·산성 호수·낙뢰 고원), 초기 숲 배경과 아이콘 아틀라스는 **내장 imagegen**으로 새로 생성하고 `public/assets/`에 저장했습니다. 유료 API/CLI 대체 경로를 사용하지 않았습니다. 캐릭터 6종은 기존 Grok 원본 영상에서 동작별 24프레임을 512×512로 직접 재추출했습니다. 프레임별 위치 보정 없이 6개의 4096×1536 RGBA 무손실 WebP 동작 시트로 배포하며 캔버스에는 256×256으로 표시합니다. 시트·좌표는 `public/assets/character/<appearance>/`, 초상화는 `public/portraits/`에 있습니다. [512px 추출·검증 기록](docs/sprite-512-validation.md)을 참고하세요. 작업용 원본 영상·개별 시트·기존 런타임 시트 백업은 Git 제외된 `art-workbench/sprites/`에 보관합니다. 원본과 TacticsSD 코드·스킬은 변경하지 않았습니다. 자산 출처·해시는 `public/assets/manifest.json`, 생성 기록은 `ASSET-PROMPTS.md`에 있습니다. PixiJS 8.21.0의 공식 배포본과 CSP 호환 모듈을 로컬 설치본에서 복사했으며 라이선스는 `public/PIXI-LICENSE.txt`에 포함했습니다. Three.js 코드와 의존 파일은 제거했습니다.

### 6자리 숫자 비밀번호

회원가입과 로그인은 ASCII 숫자 정확히 6자리를 사용합니다. 화면은 가려진 네모 6칸이며 숫자 키패드 힌트, 선행 0, 붙여넣기와 키보드 편집을 지원합니다. 사용자 요청에 따라 로그인·가입 시도 횟수 제한은 없습니다. scrypt 해시, HTTPS 설정과 세션 검증은 유지합니다.

### 관리자 설정

서버 실행 후 관리자 계정으로 로그인하면 상단에 **관리자 설정**이 표시됩니다. 관리자도 여관에서 캐릭터를 직접 생성해야 합니다. 관리자에게는 최초 1회 모든 지역의 탐험 기록과 네 지역 체크포인트를 지급합니다. **내 전체 지도·체크포인트 획득** 버튼은 성장·장비·현재 위치를 바꾸지 않고 기록을 다시 채웁니다.

계정 목록의 **초기화**는 모든 캐릭터·소지품·금화·모험 및 탐험 기록을 지우고 캐릭터 0명의 여관 상태로 돌아갑니다. 로그인 정보·관리자 권한·지도 구조는 유지됩니다. 관리자도 초기화 후 지도 기록을 다시 자동 지급받지 않습니다. 동일 요청 재시도는 한 번만 적용하며 이전 화면의 명령은 거절합니다.

삭제할 계정을 선택하고 그 아이디를 정확히 다시 입력하면 해당 계정의 세션·저장 진행·장비·맵·사건·요청 기록을 한 트랜잭션으로 삭제합니다. 현재 로그인한 관리자와 마지막 관리자는 삭제할 수 없습니다. 일반 가입 계정은 관리자 권한을 얻지 않습니다.

검증은 관리자 단위·HTTP 통합 테스트와 격리된 테스트 계정의 실제 브라우저 흐름으로 수행합니다. 실제 운영 계정을 삭제하거나 초기화하는 테스트는 수행하지 않습니다. 관리자 계정과 비밀번호는 저장소에 포함하지 않습니다. 새 설치에는 관리자가 자동 생성되지 않으며, 일반 가입으로 관리자 권한을 얻을 수 없습니다. 관리자 권한은 서버 운영자가 해당 설치의 DB에서 별도로 지정해야 합니다.

### 캐릭터 동작 재생

- HOME·갈림길·일반 보물: 정면 Idle 반복. 이동: 측면 Walk 반복, 왼쪽 이동은 반전.
- 전투 대기: 측면 Attack의 첫 프레임. 공격/시전: 650ms, 실제 피해를 받았을 때 Hit: 360ms. 빗나감에는 움찔하지 않습니다.
- 전투·보스 승리: 마지막 공격 후 정면 Victory를 2초간 재생합니다. 일반 보물 획득은 승리 동작을 트리거하지 않습니다.
- 패배: 마지막 Hit 후 Down을 1.5초간 재생하고, 귀환 중에도 마지막 프레임을 유지합니다. HOME에서 Idle로 복귀합니다.
- 동작마다 원본 영상에서 다시 고른 24프레임을 사용하며 `public/hero-animation.js`에서 재생 시간을 조절합니다. 최초 접속·재접속의 과거 전투 기록은 재생하지 않습니다.
- 모든 외형과 여관 미리보기는 같은 프레임 계산 함수를 사용합니다. `npm run test:sprites`는 등록된 모든 캐릭터의 `sprite.json` 동작별·프레임별 재생 시간, 반복/마지막 프레임 유지, 144프레임 배치와 실제 PNG 규격을 검사합니다. 캐릭터별 재생 시간·프레임 수 예외는 허용하지 않습니다.
- 2026-10-16 재추출 후 동작 구간·반복 연결·투명 가장자리와 브라우저 재생을 검수했습니다. 걷기는 한 주기 24프레임을 1.2초(20fps), Idle은 2초(12fps)에 재생합니다. Wizard의 정면·측면 Base는 의상과 머리 장식이 서로 달라 그 차이가 유지됩니다.

### 캐릭터 표시 크기와 이동 배경

내부 좌표 기준 캐릭터 셀은 모험 중 192×192, 여관에서는 154×154이며 모험 중 발 기준은 y=317입니다. 전투·보물 장면의 캐릭터는 x=166, 신규 몬스터는 196×196 크기로 x=374, y=330에 표시합니다. 기존 보스·상자는 x=398, y=317을 유지합니다. 세로 배치에서는 이 좌표와 크기가 화면 배율에 맞춰 함께 조정됩니다. 이동 배경은 매 이동 시작 시 중앙에서 출발해 6초 동안 일정한 속도로 진행 방향의 끝까지만 움직입니다. 서버 갱신으로 이동 위치를 보정하거나 타이머를 다시 시작하지 않습니다. 이동이 끝나면 중앙으로 돌아갑니다. 동작 줄이기 설정에서는 배경을 중앙에 고정합니다.

아트 제작 자료는 `art-workbench/`로 통합하며, 폴더 전체를 Git에서 제외하고 로컬에 보관합니다. `sprites/`는 캐릭터 제작, `equipment/originals/`는 장비 원본, `ui-icons/`는 UI 아이콘 원본·색상 정보, `backgrounds/route-map/`는 지도 배경 제작 기록을 보관합니다. 게임용 완성본은 `public/assets/`에서 사용합니다.

- **세로 배치:** 가용 너비가 806px 미만이면 모험 화면을 창 너비에 맞춰 4:3으로 표시합니다. 내부 512×384 좌표와 렌더러 해상도 2는 유지하고, 화면 안내와 클릭 영역을 함께 확대·축소합니다. 가로 배치는 기존 고정 크기를 유지합니다.

관리자 설정의 **지도·체크포인트 초기화**는 현재 관리자 자신의 모든 지역 지도를 재생성하고 탐험·체크포인트를 초기화합니다. 확인창에서 본인 아이디를 입력해야 실행되며, 이동·전투를 종료하고 새싹마을 여관에서 출발 대기합니다. 캐릭터·성장·현재 HP·소지품·금화·도감은 유지되고, 재접속 후에도 전체 지도·체크포인트가 자동으로 지급되지 않습니다. 다시 공개하려면 옆의 **내 전체 지도·체크포인트 획득** 버튼을 사용합니다.

장비 카테고리별 숙련 ON/OFF 12종과 직접 스킬 18종은 [스킬 규칙](docs/skills.md)을 따릅니다. 숙련은 장착 중인 장비에 맞는 경우만 적용되며 무기·갑옷 숙련 보정은 합산합니다.

캐릭터 시트 36장과 캔버스 배경 6장은 RGB·알파를 보존한 무손실 WebP로 배포합니다. 원본 PNG는 `art-workbench`에 보관합니다. [변환·검증 기록](docs/lossless-webp-validation.md).
